# 本地项目备份与恢复

导出已保存项目元数据和项目目录的全部常规文件（参考素材、前置素材/候选、步骤产物、时间线、已有输出与历史）。不包含应用级配置、凭据、模型或浏览器草稿。活动任务存在时拒绝快照。ZIP 包含版本化清单和逐文件 SHA-256；导入校验路径、重复项、文件类型、容量与摘要，失败不创建项目。成功恢复到新 UUID 项目，原项目不变，内部项目 URL 和受管路径更新。不自动运行任何任务。界面提供项目导出及首页恢复；只用现有依赖。

首版限制：最多 10000 个文件，解包总量 4 GiB，JSON 单文件 16 MiB，上传 ZIP 最多 4 GiB。完整性校验不替代来源可信性，不运行归档内代码。
