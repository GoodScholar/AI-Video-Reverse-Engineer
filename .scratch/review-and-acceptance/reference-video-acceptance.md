# 首轮验收：参考视频的结构与节奏复刻

## 已确认范围

依次验收参考视频 → 三维白模渲染视频 → 灰度深度视频，随后再做人物动作迁移或商品精准替换专项。首轮采用 10–15 秒、3–5 镜头、单商品、简单背景、无人物和复杂文字的参考视频。最终生成在外部完成；不下载安装依赖或模型，不默认发送素材到外部服务。

## 验收入口

- 用户提供或指定参考视频本地路径。
- 明确使用已有生成环境地址、工作流与模型；检查就绪状态与实际输入接口。
- 若环境涉及素材外发、计费或尚未安装的依赖，先明确具体对象和必要授权。
- 复制为独立验收项目，保留参考文件，不覆盖既有项目编排。

## 执行步骤及证据

1. 读取视频实际时长、帧率、尺寸和可解码性；记录文件 SHA-256。
2. 使用现有拆镜工具形成切点，并人工复核是否为真实镜头切换。逐镜记录起止时间、时长、主体位置与大小、视角、商品运动和运镜；无法观察的内容标记不确定。
3. 整理逐镜提示词和必要参考图，导出交付包。记录最终实际执行的工作流、模型版本、参数、种子及输入素材，不把候选模板当已验证工作流。
4. 在已确认环境逐镜生成，保留原始结果与运行记录；失败或效果不符如实记录，不以复制参考视频或测试片替代生成结果。
5. 回填结果，设置参考片段起点，同步对比；每次候选修改记录差异。
6. 按参考镜头顺序导入时间线，保持目标时长，渲染导出；复核镜头边界、全片时长、画面与音轨。首轮以画面为主，不新增 AI 音频生成范围。

## 本轮操作性判定标准

以下用于第一轮样例对照，不代表模型普遍能力或行业标准。

| 项目 | 通过条件 | 证据 |
| --- | --- | --- |
| 分镜 | 镜头数量与顺序一致，无漏镜、额外镜头 | 两侧镜头表 |
| 节奏 | 最终剪辑各镜头边界相差不超过 1 个导出帧；无不足时长补黑或末帧硬凑 | 时间线参数、成片检查 |
| 构图 | 逐镜开头/中间/结尾的主体位置、大小和观察角度与计划对应 | 三处对照截图和人工记录 |
| 运镜与运动 | 静止/推进/拉远/横移等主要运动类别、方向和先后关系一致；无明显反向或突变 | 同步播放观察 |
| 商品可辨识性 | 主体数量稳定、轮廓合理，无明显融化或多出部件；不据此声称标签或品牌精准保真 | 全片人工复核 |
| 流程完整性 | 原始生成结果可溯源，能回填、替换、保存、渲染和再次打开 | 输入/结果/交付包/导出文件与记录 |

时间线对齐仅证明剪辑节奏；必须单独评价未裁切生成片段的动作和运镜，避免剪辑掩盖模型效果。对照步进采用浏览器时间定位，不宣称解码级逐帧精确。任一核心维度未通过则记录失败或部分通过，不用平均分抵消。
