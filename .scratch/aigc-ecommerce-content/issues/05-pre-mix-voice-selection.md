# 混剪前多音色试听与选择

Status: ready-for-human

属于第二阶段完整目标的自动配音扩展，入口直接放在现有工作台的 AI 混剪生成配置中。用户在 2026-09-26 明确要求：AI 混剪之前就展示多种音色，且音色支持试听。

## 工作台顺序

填写商品事实、卖点与受众并上传或选择授权素材 → 查看并确认本次 AI 请求 → AI 生成 5 条脚本候选 → 编辑并确认脚本 → 多音色试听 → 选择音色 → 按确认脚本生成对应配音与 AI 混剪 → 声画字幕预览 → 审核 → 导出。

脚本生成复用已有 AIGC 创作简报与候选流程；此任务新增混剪前的音色试听和选择，不把脚本生成步骤省略为要求用户自行准备文案。

## 验收要求

- [x] 混剪生成前可见多种标准音色，每种均展示名称、性别、音质特点、语言/口音和适用场景，供先筛选再试听；均有可播放的试听音频。
- [x] AI 生成的脚本候选经编辑、确认后可继续音色选择；最终配音与混剪使用当前已确认脚本版本。修改脚本后重新确认并生成受影响的配音、预览和审核。
- [x] 同一句短文案用于音色比较，无须先生成成片才能试听；播放另一种音色时停止上一段，避免重叠。
- [x] 用户选择音色后在生成配置中明确显示所选项；配音生成实际使用该音色，批量变体可追溯音色与配音版本。
- [x] 支持“都不满意”并更换一组继续试听，保留素材、文案和已编辑内容。
- [x] 试听失败、服务不可用或余额不足时显示实际原因，不伪造试听成功，也不静默采用用户已拒绝的系统音色。
- [x] 配音进入成片声音轨道，与镜头和字幕对应；声画完整性须在同一条最终 MP4 中检查。
- [x] 更换音色或配音后重新预览和审核，旧批准不得用于新版导出。
- [ ] 用户接受至少一种音色，正式供应方案、商用授权与费用已核验，真实试听和完整成片验证通过。

## 历史缺口（正式接入前）

现有 `BatchEditor` 没有音色库、试听和选择接口；此前 macOS 系统音色试听已被用户拒绝；本轮 Qwen 音色已获初步认可。专业音色试生成因当前 fal 账户余额不足返回 403，未取得专业试听音频；工作台运行时的正式配音供应配置亦未接通。先解决正式音色与服务可用性，再按上述入口顺序实施，不把规划记录计作产品功能完成。

2026-09-26 补充：用户确认配音不必依赖 Fal，随后批准用 uv 建立独立本地环境，下载并测试 Qwen3-TTS 0.6B CustomVoice 8bit。已完成四种预置音色、长文及流式离线试跑；51.2 秒音频生成耗时 20.6 秒，暖机短文 RTF 约 0.38，MLX 峰值约 9.1 GB。详见 `docs/research/local-qwen-tts-test-results-2026-09-26.md`。Fal 余额不足只影响该云端渠道，不是本地测试或后续本地接入的必要条件。用户现已初步认可四种样音，并要求每种音色有描述，DEV 原型已展示对应说明与同文案真实试听；正式试听、选择与配音接口仍未接入，任务状态保持 `needs-info`。
