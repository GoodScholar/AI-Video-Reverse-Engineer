# 01：从创作简报生成五条脚本候选

**What to build:** 交付人员在项目中保存电商商品创作简报、选择已有图片或视频，查看本次将发送给已配置 AI 服务的完整文字和服务身份，逐次确认后生成并保存五条结构化脚本候选。

**Blocked by:** None (can start immediately).

- [x] 简报含商品事实、受众、卖点、行动引导、禁用表达及项目素材引用；缺少必要商品事实或画面素材时给出可行动错误。
- [x] 发送前展示真实请求文字、服务和模型；取消确认时不发请求，原始图片、视频、本地路径和凭据不进入文本请求。
- [x] 五条候选分别显示卖点、屏幕文案、镜头素材与事实依据；结构无效、重复候选、无效引用和禁用表达明确失败，不以虚构内容补足数量。
- [x] 生成失败或服务配置变化不覆盖已保存简报和旧候选，项目重新打开后仍可查看历史候选。
- [x] 项目 API 与工作台测试覆盖成功、拒绝发送、错误响应和保存恢复；用可控假服务核对实际请求内容。

## Comments

完整范围见 [规格](../spec.md)。真实客户脚本质量仍需人工验收。

已在项目工作台实现简报、逐次披露与五条候选，并用可控服务验证请求边界、保存和重复内容校验。真实客户内容质量转入人工验收。
