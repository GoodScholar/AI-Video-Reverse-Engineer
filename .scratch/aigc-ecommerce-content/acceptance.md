# 电商商品短视频首期真实素材验收

Status: ready-for-human

本清单用于验证真实客户商品的脚本质量、画面匹配与最终交付。自动化测试和合成素材已验证技术流程；此处只记录人工验收结果，不在文档中保存客户原始素材、完整商品资料或服务凭据。

所需客户资料可通过[商品短视频试点资料问卷](../../to-questionnaire-ecommerce-video-acceptance.md)收集。

## 验收输入

- 一个已获准用于制作和交付的商品样例：商品名称、至少一条可核实的商品事实及其依据、目标受众、期望卖点、行动引导和禁用表达。
- 同一商品至少两段已授权的图片或视频素材，以及供交付人员核对的素材名称、类型和备注。商品事实与素材说明应由客户或交付负责人确认。
- 工作台中已配置且在本次验收前重新验证的 AI 服务。每次生成脚本前，由交付人员在工作台查看目标服务、模型及完整发送文字并显式确认；原始图片或视频不得随脚本请求发送。

## 执行与通过标准

| 步骤 | 操作 | 通过标准 |
| --- | --- | --- |
| 1. 建立简报 | 导入商品素材，填写事实、受众、卖点、行动引导和禁用表达并保存 | 重新打开项目后简报与素材引用仍准确；至少两段画面可用 |
| 2. 核对发送内容 | 预览请求文字、服务和模型，先取消一次，再逐次确认发送 | 取消不产生生成请求；发送内容仅含已核对的文字和素材名称、备注，不含原始媒体、路径或凭据 |
| 3. 审核五条候选 | 检查每条卖点、屏幕文案、事实引用、素材引用和镜头顺序；必要时编辑并重新确认 | 五条均无无依据的商品声明或禁用表达；差异体现在卖点或叙事角度，不只是换词；每条可追溯到当前简报 |
| 4. 交接与预览 | 将五条已确认候选交给批量混剪；至少预览两条镜头安排不同的变体 | 各变体独立；屏幕文案与镜头对应且可逐句修改；单条素材失败不覆盖其他变体或人工编辑 |
| 5. 审核与导出 | 对至少两条成片核对画面、字幕可读性、商品事实与授权，批准后导出 MP4 | 导出文件与已批准预览一致，屏幕文案已烧录；未批准或审核过期的版本不能导出 |

客户或交付负责人应记录五条候选及两条成片的通过／退回原因。若脚本质量或事实准确性不达标，先修订简报或候选，再按相同的逐次确认流程重试；不以自动化测试通过代替商业内容验收。
