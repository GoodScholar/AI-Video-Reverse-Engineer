# 视频工具后续开发

用户已授权继续开发。承接上一轮：补充分镜编辑联动、自动处理流程，并核查实际模型验收条件。角色动画与动作迁移保留；外部 ComfyUI 不作为本机开发前置条件。

## 本轮成功标准

- 用户能把当前参考视频的已保存分镜结果应用到镜头准备，或恢复原检测边界；独立保存，不改预处理原件。
- 起止完全一致的草稿保留；变化的镜头不继承旧提示词、分析和人物控制结果；异步迟到结果不覆盖新边界。
- 可提交至少两个有序本地处理步骤。分析步骤产物独立，视频变换步骤自动向后传递视频。
- 任务持久化，缺少依赖提交前提示；取消阻止后续，失败可从未完成步骤继续，重启不静默重复执行。
- UI 可操作并有步骤状态和产物入口；保持现有单工具、超分、角色动画入口。
- 自动化验证输入隔离、版本冲突、取消、失败恢复；利用本机已有真实工具补充烟雾验证，不把模拟推理写成模型实测。

## 实施与验证

1. 分镜应用和恢复 → 后端生命周期/边界测试、前端交互测试。
2. 自动处理流程 → 依赖预检、真实输入衔接、取消/失败续跑/重启测试。
3. 整合 → 受影响检查、构建、独立审查、真实轻量工具冒烟与文档更新。

Ruling: 延续已有本地模型与外部执行器策略，不自动安装 ComfyUI 或下载大模型。缺失模型验收明确保留，不以接口测试代替效果验证。
Ruling: 在当前工作区增量修改，以保留上一轮尚未提交的相关实现，不创建丢失这些实现的新工作树，不提交 Git。
