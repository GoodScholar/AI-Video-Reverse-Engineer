# 04: 统一冻结素材字节与渲染输入准备

Status: resolved
Type: task
Blocked by: 02

## What to build

统一时间线与批量混剪从稳定项目素材标识生成冻结渲染输入的规则，包括安全解析、复制、内容核验和失败回收。该模块不拥有可恢复运行状态、短视频审核或交付决定。

## Current Evidence

- `timeline_api.py` 与 `batch_editing_api.py` 都遍历片段、解析素材文件、复制来源并在失败时清理。
- 批量交付还需要核对当前原素材与批准预览冻结来源是否一致，形成第三套相关文件规则。
- 符号链接、缺失文件、素材变化与部分复制失败分别由不同调用方测试。

## Acceptance Criteria

- [x] 一个内部模块统一稳定素材标识到冻结字节的安全解析、复制、内容核验和失败回收。
- [x] 时间线渲染与批量预览通过同一规则冻结当前项目素材，不直接拼接素材路径或各自清理半成品。
- [x] 批量交付可以核验并复制具体已批准预览的冻结来源；新预览、原素材变化或缺失不得误用旧来源。
- [x] 路径穿越、符号链接、非普通文件、缺失文件、部分复制失败和内容变化都有模块接口级测试。
- [x] `durable_runs` 继续拥有运行状态与恢复；`batch_production` 继续拥有审核、交付和变体有效性。
- [x] 保持现有冻结快照结构、来源目录、HTTP 响应、错误码、渲染输出和历史运行兼容。
- [x] 不搬迁项目素材，不新增内容寻址存储、去重仓库或外部对象存储。

## Likely Scope

- `backend/app/timeline_api.py`
- `backend/app/batch_editing_api.py`
- 新的渲染输入准备模块
- `backend/tests/test_timeline_api.py`
- 批量预览、导出和素材变化测试
