# 视频工具与角色动画

用户已批准本轮同时开发分析、角色动画/动作迁移和成片处理。用户本机没有 ComfyUI。复用本地/局域网 ComfyUI 架构，不安装 ComfyUI 或大型模型，不自动上传云端，不发起付费调用。

## 验收范围
1. 独立角色图与驱动视频素材，Wan 角色动画/动作迁移方案、参数、环境检查、工作流导出和显式生成。模型/节点缺失明确显示；真实执行未经验证不得宣称成功。复用已有运行状态及未知提交恢复语义。
2. 本地分析工具：PySceneDetect 自适应分镜和切点修正，whisper.cpp 字幕导出，SAM 2 主体点选跟踪遮罩。外部工具可选依赖，缺失显示安装/配置说明，执行为真实调用，不得用演示结果冒充。
3. 成片处理：统一选择当前参考视频与已保存生成/处理结果、同步对比、RIFE 补帧和批量任务（取消、失败重试）；复用现有超分。

## 约束
- 保留全部已有未提交修改；不提交、不创建 worktree 搬迁、不删除现有文件。
- 新模型在独立 worker 运行，主应用不导入大型模型。现有后端 Python 3.9 兼容。
- 本地素材路径、产物路径需校验归属和符号链接；导出仅已验证产物。
- 状态持久化、输入快照、重启中断处理、项目切换迟到响应保护。
- UI 中文，明确区分未配置、排队、执行、失败、完成。无服务也能保存/导出方案。
- 不因缺少 GPU 自动改用付费服务；不下载大型权重。界面/API 自动化测试与真实模型验收分别报告。
