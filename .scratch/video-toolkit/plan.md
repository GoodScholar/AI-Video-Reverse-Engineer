# 视频工具与角色动画实施计划

Goal: 同时实现用户批准的视频分析、动作迁移和成片处理操作链路。
Architecture: 复用项目存储和计算队列，独立 worker 承担可选模型；ComfyUI 保持外部执行器。
Spec: .scratch/video-toolkit/spec.md

1. 角色动画链路：独立素材与方案、固定官方来源候选工作流、环境检查/导出/运行、前端。先测试无环境和输入生命周期，再实现、跑相关检查、审查。
2. 分析工具：项目级持久任务、PySceneDetect/whisper.cpp/SAM 2 适配、编辑切点、产物预览导出；界面明确缺失依赖。验证状态转换、输入/产物隔离及实际轻量分镜样例。
3. 成片处理：素材选择、同步对比、RIFE worker、批量任务/取消/重试，衔接超分。验证输入替换隔离、任务生命周期、比较同步、构建。
4. 整合检查、独立审查、修复、更新 README 和各项验收记录。无真实 GPU 的生成/SAM 2 不标为实测成功。

不产生 git commit；在当前共享工作区精准修改。用户项目规则优先于技能的额外流程。

## 最终实施与验收

已完成代码、接口、界面和相关回归；真实ComfyUI/SAM2/whisper/RIFE模型验收受未安装环境限制，未冒充推理成功。工具独立审查通过，角色后端和UI重要发现已修并经限定复查。最后新增回归保持旧草稿revision并将新角色未绑定hash标为stale。

Ruling: 不安装ComfyUI或大模型，保持外部执行器与离线包；这与用户当前无环境事实匹配，代价是本轮不能验证真实生成效果。
Ruling: 采用官方Move角色图背景模式，不启用固定选点的replacement分支；主体替换需要后续交互式掩码设计，代价是当前没有视频背景内主体替换入口。
Ruling: 分镜切点编辑独立保存到工具结果，不覆盖旧逐镜头分析，避免破坏用户已有方案。
