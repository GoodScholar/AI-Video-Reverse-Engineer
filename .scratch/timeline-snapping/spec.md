# 时间线吸附与快捷键

仅前端本地剪辑体验，使用现有依赖。
- 拖动片段首尾在八屏幕像素内吸附零点、播放头和其他片段边缘；默认开启，可切换，Alt 临时关闭。
- 不产生同视频轨重叠或越出 0..300 秒，不吸附自身；一次拖动可一次撤销。
- 快捷键仅时间线范围内生效，输入框/可编辑区域/媒体播放器/输入法组合输入保持原行为，忙碌与拖动时不执行键盘编辑。
- S 分割、Cmd/Ctrl+D 复制、Delete/Backspace 删除、Cmd/Ctrl+Z 撤销、Cmd/Ctrl+Shift+Z 或 Ctrl+Y 重做、Cmd/Ctrl+S 保存。
- 左右方向键移动播放头一个项目帧，Shift 十帧；不承诺实时草稿视频预览。
- 有简洁说明；验证吸附开关、Alt、缩放阈值、防重叠、键盘输入保护及撤销。
