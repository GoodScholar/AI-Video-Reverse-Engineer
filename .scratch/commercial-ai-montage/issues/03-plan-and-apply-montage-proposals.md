# 03: 生成并采用可解释混剪提案

**What to build:** 让内部交付人员从已确认脚本和已索引项目素材生成一份完整混剪提案。提案按脚本段落选择素材片段候选，确定镜头入点、持续时间、顺序和节奏吸附点，抑制重复并保持跨变体差异；每项决定均可解释、可替换。用户确认后，提案写入现有短视频变体编辑序列，而不是建立第二套时间线或自动批准成片。

**Blocked by:** 02: 实现本地召回与豆包视觉复排。

**Status:** resolved

- [x] 一条已确认脚本可以生成覆盖全部脚本段落的混剪提案，提案包含有序镜头、源入点、持续时间、候选依据和未满足项。
- [x] 规划器同时考虑旁白时长、词边界、音乐节拍、素材质量、镜头重复和语义连续性；对白和脚本语义优先于节拍吸附。
- [x] 规划结果不包含源区间重叠或越界，单个候选不足时明确返回缺口而不是重复填充或伪造素材。
- [x] 同一批次生成多个短视频变体时记录共享素材使用情况，并按可解释规则形成镜头差异。
- [x] 用户可以为任一脚本段落查看并替换备选候选、调整入点或时长，并保留系统原建议用于对照。
- [x] 应用提案使用现有变体修订校验，形成普通可编辑的变体编辑序列和新变体版本。
- [x] 已存在人工编辑时，重新应用提案必须显式选择覆盖、合并或放弃，不能静默改写当前编辑序列。
- [x] 规划器输入、输出和选择理由可冻结、恢复和追溯；源索引或复排结果过期时不允许无提示应用旧提案。
- [x] 自动化测试覆盖脚本覆盖、时长、区间安全、重复抑制、跨变体差异、节拍优先级、确定性、人工替换和修订冲突。
