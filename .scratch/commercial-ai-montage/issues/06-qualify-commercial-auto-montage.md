# 06: 自动质检并完成商用金标验收

**What to build:** 对混剪链生成的实际冻结预览执行可解释自动质检，并使用用户指定参考视频结构完成首轮商用自动混剪验收。质检报告必须给出可回跳的时间范围和证据，阻止存在明确工程错误的交付，但不能自动批准内容；金标验收要记录自动初稿保留率、人工替换率和实际成片质量，而不是只验证接口成功。

**Blocked by:** 04: 实现转场与音频交叉淡化; 05: 实现竖屏裁满、花字和字幕模板。

**Status:** ready-for-agent

- [ ] 自动质检绑定一个具体冻结预览、编辑序列修订、字幕和包装模板版本、源指纹及规则版本。
- [ ] 质检检测黑帧、卡帧、非预期静音、响度异常、黑边、输出规格、字幕或花字越界、片尾缺帧和声画时长异常。
- [ ] 每项发现包含严重级别、时间范围、规则和证据，用户可以从报告跳转到预览对应位置复核。
- [ ] 明确工程错误可以阻止交付并给出修复入口；警告保持可审核，任何质检结果都不能自动产生人工审核通过状态。
- [ ] 编辑序列、转场、裁剪、包装、字幕、音频或源素材改变后，旧质检与旧批准正确失效并保留历史。
- [ ] 使用用户指定参考视频的结构和合法项目素材生成至少一条完整自动初稿，记录系统建议、所有人工替换和最终冻结编辑输入。
- [ ] 金标结果达到至少 80% 镜头保留、人工替换不超过 20%，且最终 9:16 画面无非预期黑边、主体与字幕在安全区、转场和花字完整。
- [ ] 对批准预览和最终导出执行逐帧或关键边界对照、实际解码、分辨率、帧率、编码、音轨、时长和内容哈希核验。
- [ ] 完成桌面完整操作、关键键盘路径和移动只读查看验收，并运行受影响后端、前端、真实媒体和生产构建检查。
- [ ] 验收报告准确区分商用自动混剪专项通过、真实客户商业交付验收和实际投放效果，不扩大完成声明。
- [ ] 首个金标通过后登记另外两组不同素材的回归集需求；未取得合法素材前保持待办，不用合成数据冒充真实质量证据。
