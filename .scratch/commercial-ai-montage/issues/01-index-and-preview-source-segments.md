# 01: 建立可播放的素材片段索引

**What to build:** 让内部交付人员能够为内容项目中的授权视频素材建立可恢复的片段级索引，并在现有商品视频制作流程中查看每个素材片段候选的来源、入点、出点、关键帧和可播放预览。索引是项目素材的可重建派生物，源文件、算法或模型版本改变后必须明确失效，不得建立第二套素材身份。

**Blocked by:** product-scope-freeze 06: 收口 P0 全链路与交付证据。

**Status:** ready-for-agent

- [ ] 用户可以从现有项目素材选择一个或多个视频启动片段索引，并看到排队、运行、完成、失败、取消和重试状态。
- [ ] 场景检测输出同一素材内多个稳定的源时间区间；每个候选均保留项目素材身份、源指纹、算法版本和关键帧证据。
- [ ] 同一长视频的不同镜头不会按素材身份提前折叠为单一结果，候选预览从正确入点开始播放且不越过源文件尾部。
- [ ] 应用重启后索引运行和已完成结果可恢复；迟到或旧版本结果不会覆盖新源或新算法产生的状态。
- [ ] 源文件不可用、源指纹变化或算法版本变化时，旧索引被标记为过期并说明原因，不静默用于后续选片。
- [ ] 索引数据只引用稳定项目素材身份，不以绝对路径、向量 ID 或结果序号作为业务身份。
- [ ] 界面沿用现有内容工作室设计，清楚区分项目素材、素材片段候选和已经进入变体的正式剪辑片段。
- [ ] 自动化测试覆盖切分区间、同源多候选、预览区间、取消恢复、版本失效、迟到结果和源文件缺失。
