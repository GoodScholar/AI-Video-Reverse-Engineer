# 01: 贯通视频比例选择

Status: resolved
Type: task
Blocked by: none

## What to build

按 [规格](../spec.md) 与 DESIGN.md 视频比例规范实现选择、保存恢复、智能解析与实际制作输出。执行前核对现有设置、变体及渲染契约。

## Acceptance criteria

- [x] 七种选择可键盘操作、保存与恢复，窄屏不造成页面横向溢出
- [x] 商品默认9:16、复刻智能；智能解析显示实际比例及依据
- [x] 项目默认、批次继承与单条覆盖一致，现有作品不被静默改写
- [x] 比例和分辨率分开，完整适配与字幕安全区随画布变化
- [x] 比例变更使旧预览/审核失效，有效配音可复用
- [x] 渲染和导出的真实尺寸保持选择比例，各比例至少有一次实际媒体检查

## Comments

2026-09-27 已实现并验证：前端七项比例控件接入商品创作、单条精修与复刻；后端保存解析、批次继承、审核失效和真实渲染已贯通。验证结果：前端 375 项通过；后端 1272 项通过、9 项跳过；生产构建通过。
