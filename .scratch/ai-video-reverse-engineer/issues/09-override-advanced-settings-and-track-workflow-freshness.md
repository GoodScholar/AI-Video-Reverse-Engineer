# 09: 覆盖高级设置并管理 Workflow 新鲜度

**What to build:** 让 ComfyUI 创作者按需覆盖比例、分辨率、时长、音频和生成数量，并确保任何影响输出的修改都会使旧 Workflow 明确失效。

**Blocked by:** 08/生成并下载 Wan2.2 14B I2V 复刻包

**Status:** wontfix

> 参数覆盖、智能解析和方案新鲜度已由后续增量功能分别实现；本票中的“可发送到本地 ComfyUI”与 ADR 0007 冲突，因此不再按原票实施。

- [ ] 智能模式默认隐藏技术复杂度，高级设置作为同一流程中的可展开区域存在。
- [ ] 用户能够覆盖视频比例、分辨率、生成时长、音频保留或移除以及生成数量。
- [ ] 视频输出格式在 MVP 中固定，不提供 MOV 输出选项，也不引入视频编辑、延长或版权 IP 模式。
- [ ] 每项覆盖都按当前模型能力校验，非法组合会阻止 Workflow 生成并提供可操作说明。
- [ ] 用户能够恢复智能匹配值，并看到恢复后实际采用的参数。
- [ ] 修改结构化分析、Prompt 或任何输出参数后，已有 Workflow 明确标记为需要重新生成。
- [ ] 过期 Workflow 不允许直接发送到本地 ComfyUI，但仍可查看其历史版本信息。
- [ ] 重新生成后，新 Workflow 与当前复刻方案版本一致并恢复可下载、可发送状态。
- [ ] 刷新或重新打开项目后，覆盖参数、智能匹配状态和 Workflow 新鲜度保持正确。

## Answer

保留可编辑参数、智能比例、版本过期与候选包下载；删除直接发送语义。后续参数功能必须绑定当前方案版本，但不恢复应用内最终生成。
