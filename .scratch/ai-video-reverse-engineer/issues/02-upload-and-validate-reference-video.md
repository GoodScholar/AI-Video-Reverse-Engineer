# 02: 上传并校验参考视频

**What to build:** 让用户为复刻项目上传参考视频，在分析前获得格式、时长、体积、分辨率和可读性的明确校验结果。

**Blocked by:** 01/创建并恢复复刻项目

**Status:** ready-for-agent

- [x] 用户能够通过文件选择或拖放上传 MP4、MOV 参考视频。
- [x] 上传区域在选择文件前明确展示 2～10 秒、最大 200 MB、最低 480P 和最高读取 4K 的限制。
- [x] 系统能够读取并展示参考视频的格式、时长、分辨率和帧率等基础信息。
- [x] 不支持的格式、短于 2 秒、长于 10 秒、超过 200 MB、低于 480P 或无法解码的文件会阻止分析。
- [x] 每种阻止原因都提供具体说明，不使用笼统的“上传失败”代替。
- [x] 合法参考视频与复刻项目关联保存，重新打开项目后无需再次选择文件。
- [x] 选择新参考视频时明确提示它会替换当前输入，且不会误删其他复刻项目。
- [x] 上传和错误状态不只依赖颜色表达，并可通过键盘操作。
