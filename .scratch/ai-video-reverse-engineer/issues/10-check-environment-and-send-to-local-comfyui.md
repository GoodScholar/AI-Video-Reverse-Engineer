# 10: 检查环境并发送到本地 ComfyUI

**What to build:** 让用户检查本地 ComfyUI 的连接与依赖状态，并在环境完整时发送当前可执行工作流、进入 Queue 和追踪执行结果。

**Blocked by:** 08/生成并下载 Wan2.2 14B I2V 复刻包

**Status:** wontfix

> ADR 0007 已关闭新的应用内最终生成提交。本任务保留为历史记录，不再领取；候选工作流下载继续由现有复刻方案功能提供，历史运行记录继续可读。

- [ ] 用户能够配置并验证本地 ComfyUI 连接，连接失败不会阻止分析或复刻包下载。
- [ ] 环境检查分别展示连接、版本、所需模型和所需节点状态，不以单一“环境异常”代替具体信息。
- [ ] 缺少模型、节点或版本不兼容时，界面列出具体缺失项并阻止直接发送当前 Workflow。
- [ ] 产品不会擅自安装、下载或修改用户的 ComfyUI、节点和模型。
- [ ] 环境完整且 Workflow 为当前版本时，用户能够一键发送到本地 ComfyUI 并进入 Queue。
- [ ] 用户能够看到已发送、已 Queue、运行中、成功和失败等可观察状态。
- [ ] Queue 或运行失败时显示来自本地 ComfyUI 的可理解原因，并保留重新发送和下载选项。
- [ ] 执行记录与对应复刻项目、Workflow 版本和本地 ComfyUI 结果关联保存。
- [ ] API 密钥不会随 Workflow 发送到本地 ComfyUI，也不会出现在执行记录中。

## Answer

应用当前对两个历史生成提交端点统一返回 `410 final_generation_disabled`。新的最终生成由用户在外部工具完成，不恢复本任务中的 Queue 与追踪入口。
