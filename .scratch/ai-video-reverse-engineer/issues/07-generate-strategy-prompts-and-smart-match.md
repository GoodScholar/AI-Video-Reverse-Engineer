# 07: 生成策略、Prompt 与智能匹配参数

**What to build:** 根据确认后的结构化分析选择可解释的复刻策略，并让用户按需生成中英文正负 Prompt 和智能匹配参数，使用户无需理解节点即可准备生成。

**Blocked by:** 06/校正并保留结构化分析

**Status:** ready-for-agent

- [ ] 系统基于当前结构化分析选择推荐生成策略，并展示简明的选择理由。
- [ ] 分析完成后不会自动生成 Prompt；用户在复刻工作台点击“生成提示词”后才发起生成请求。
- [ ] 推荐结果明确区分经过验证的可执行工作流与尚未验证的后续建议。
- [ ] 系统生成与主体、场景、动作、运镜和光线相一致的正向 Prompt 和适配策略的负向 Prompt。
- [ ] 首版同时提供中文和英文版本，并允许分别复制与编辑；不提供可灵、Runway、Veo 等平台专用格式。
- [ ] 用户能够编辑正向和负向 Prompt，修改结果保存在复刻项目中。
- [ ] Prompt 记录其依据的结构化分析版本；相关分析变更后标记为“需要重新生成”，且不会自动覆盖用户编辑。
- [ ] 智能模式默认依据参考视频与模型能力选择比例、分辨率和时长。
- [ ] 智能匹配发生能力或资源调整时，界面解释调整项与原因。
- [ ] 超出可复刻范围的项目仍可获得分析和后续建议，但不会把未经验证的策略标为可执行工作流。
- [ ] 超出可复刻范围时，生成的 Prompt 明确标记为“实验性建议”。
- [ ] 产品不展示原始 Prompt、精确还原或综合相似度百分比等无法证明的结论。
