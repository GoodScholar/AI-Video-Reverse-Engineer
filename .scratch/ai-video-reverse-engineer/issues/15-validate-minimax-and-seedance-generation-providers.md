# 15: 验证 MiniMax H3 与 Seedance 生成服务

**What to build:** 建立能力驱动的生成服务接口，为 MiniMax H3 与豆包 Seedance 2.0 提供用户自有密钥、显式素材授权、提交、状态恢复和结果关联，并用固定测试集验证参考式生成效果。

**Blocked by:** 14/生成本地深度控制素材并运行 Wan2.2 Fun Control

**Status:** ready-for-agent

- [ ] 生成服务接口保存供应商能力、适配器版本、输入快照和执行时能力快照。
- [ ] MiniMax H3 与 Seedance 适配器分别转换请求并归一化鉴权、余额、限流、输入拒绝、超时和供应商故障。
- [ ] 每次提交前展示供应商和具体素材清单；没有本次授权标识时不得上传任何素材。
- [ ] 完整参考视频默认不加入云端请求；如策略确实需要，必须获得独立授权。
- [ ] 应用重启后可用外部任务标识恢复查询，状态不确定时不得自动重新提交。
- [ ] 供应商失败不会静默切换，也不会破坏已完成的本地深度控制素材。
- [ ] 两个适配器在专项验收前显示为 `experimental`，不得称为原生深度控制。
- [ ] 固定测试集分别记录动作时间点、位置轨迹、前后层次、镜头节奏、画面退化和多次生成稳定性。
- [ ] 只有验收证据满足设计门槛后，单个适配器才可独立升为 `beta`。
- [ ] 密钥只进入系统安全存储，不进入项目、日志、导出包或前端持久化。
