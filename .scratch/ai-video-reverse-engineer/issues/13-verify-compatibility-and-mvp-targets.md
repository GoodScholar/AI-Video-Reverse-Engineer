# 13: 完成真实兼容性和 MVP 指标验收

**What to build:** 使用固定视频验收集和真实本地 ComfyUI 环境验证两个可执行工作流，锁定兼容版本，并形成可重复执行的 MVP 发布证据。

**Blocked by:** 11/支持 Wan2.2 Fun Camera 完整复刻路径, 12/提供移动端只读结果与完整可访问性

**Status:** ready-for-agent

- [ ] 建立覆盖可复刻范围边界的固定参考视频验收集，并记录样本来源、特征和预期结果。
- [ ] 在真实 ComfyUI 环境中验证 Wan2.2 14B I2V Workflow 能够导入并进入 Queue。
- [ ] 在真实 ComfyUI 环境中验证 Wan2.2 Fun Camera Workflow 能够导入并进入 Queue。
- [ ] 根据真实集成结果锁定并记录正式支持的 ComfyUI 精确版本、必要节点和模型依赖。
- [ ] 批量验收证明至少 95% 的受支持参考视频能够生成完整复刻包。
- [ ] 批量验收证明至少 95% 的生成 Workflow 能够成功导入声明的 ComfyUI 环境。
- [ ] 在环境完整时，至少 90% 的生成 Workflow 能够成功进入 Queue。
- [ ] 在明确记录的测试环境中，常规参考视频从确认分析到复刻方案就绪的时间不超过 2 分钟；外部服务排队和网络耗时单独记录。
- [ ] 验收覆盖分析服务失败恢复、本地 ComfyUI 不可用仍可下载、依赖缺失、Workflow 过期和本地项目恢复。
- [ ] 验收覆盖桌面键盘操作、移动端只读边界、可见焦点、非颜色单一传意和减少动态效果。
- [ ] 质量报告分别记录主体、场景、动作、运镜和光线表现，不使用综合相似度百分比作为发布门槛。
- [ ] 任何未达到的指标都以实际证据记录，不通过修改口径或虚构结果标记为完成。
