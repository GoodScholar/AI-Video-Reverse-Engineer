# 06: 校正并保留结构化分析

**What to build:** 让用户校正主体、场景、动作、运镜和光线分析，并在重新分析与重新打开项目时保留已确认的人工判断。

**Blocked by:** 05/呈现带时间联动的复刻工作台

**Status:** ready-for-agent

- [ ] 用户能够编辑主体、场景、动作、运镜和光线的文本与适用时间范围。
- [ ] 人工修改与自动分析来源可区分，用户能够看到哪些内容已被自己确认或覆盖。
- [ ] 输入非法时间范围或超出参考视频时长时，系统阻止保存并解释原因。
- [ ] 编辑结果会立即参与后续复刻方案生成，同时不改变原始参考视频和分析代理。
- [ ] 重新运行自动分析前明确提示人工修改的处理方式，且默认不会无提示覆盖已确认内容。
- [ ] 刷新或重新打开复刻项目后，人工修改、来源标记和时间范围保持一致。
- [ ] 用户能够放弃当前未保存修改，恢复到进入编辑前的已保存状态。
- [ ] 编辑、保存、取消和错误提示支持键盘与辅助技术理解。
