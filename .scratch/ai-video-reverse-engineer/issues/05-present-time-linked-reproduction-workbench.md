# 05: 呈现带时间联动的复刻工作台

**What to build:** 让用户在“胶片检测台”三栏工作台中同步查看参考视频、关键帧、结构化分析和复刻方案入口，并通过共享时间选择验证分析内容。

**Blocked by:** 04/配置分析服务并完成可恢复的语义分析

**Status:** ready-for-agent

- [ ] 分析完成后进入可持续返回的复刻工作台，而不是一次性结果页。
- [ ] 左栏展示参考视频、播放控制、时间轴和关键帧胶片条，中栏展示结构化分析，右栏预留复刻方案与执行区域。
- [ ] 点击带时间范围的分析条目会把视频定位到对应时间，并同步高亮时间轴、关键帧和相关分析条目。
- [ ] 拖动或播放视频时，当前时间与可见分析内容保持一致，且不会产生互相覆盖的选择状态。
- [ ] 观察事实、复刻建议和未支持能力具有不同且不只依赖颜色的视觉表达。
- [ ] 工作台采用温暖浅灰白、深炭灰、橙红强调和蓝灰辅助状态的已确认视觉方向。
- [ ] 人物、项目名、模型状态和分析内容使用受控示例或真实项目数据，不固化视觉稿中的合成事实。
- [ ] 视频播放、时间条目选择和关键帧浏览可通过键盘完成，并具有清晰焦点。
