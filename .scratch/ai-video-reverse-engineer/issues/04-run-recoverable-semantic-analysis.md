# 04: 支持参考图片与可恢复的多供应商语义分析

**What to build:** 在保留参考视频流程的前提下，让单个项目可以二选一使用参考图片或视频，并让用户明确选择七种分析方式之一获得统一、可恢复的结构化语义分析。

**Blocked by:** 03/生成分析代理并判断可复刻范围

**Status:** ready-for-agent

- [ ] 单个项目只关联一份 `ReferenceMedia`；图片与视频可以显式替换，旧视频项目可幂等迁移且无需手工修改。
- [ ] 图片支持 JPG、PNG、WebP，限制为不超过 30 MB、边长 256～5760、比例 2:5～5:2，并拒绝动画 WebP；透明图片经提示后以白底标准化。
- [ ] 图片本地预处理生成去元数据的 `normalized.png` 和受限 JPEG 分析代理；视频继续使用联系表与运动 JSON，二者不互相伪装。
- [ ] 分析开始前清楚展示将发送的代理内容、接收方和用途；不发送完整视频、原图片、原文件名、项目名或本地路径。
- [ ] 支持百炼、OpenAI GPT、豆包、Google Gemini、xAI Grok、Anthropic Claude 和本地 OpenAI 兼容服务；用户必须明确选择，不发生自动回退或静默切换。
- [ ] 云端供应商只能选择产品已验证模型；本地兼容服务允许用户输入模型名，但 Base URL 只接受回环地址。
- [ ] API Key 使用系统安全存储，前端、项目文件、日志和读取接口均无法获得密钥明文。
- [ ] 用户能够分别配置和验证各供应商凭据，界面不会再次显示完整密钥；连接测试只发送内置测试图。
- [ ] 所有供应商密钥由本地服务通过系统安全存储管理，不写入复刻项目、浏览器持久化数据或导出内容。
- [ ] 每次分析记录供应商、模型和分析版本；失败时只允许重试或由用户明确切换供应商。
- [ ] 七种分析方式返回同一严格结构；图片只记录主体、场景、构图、视角、光线、色彩和风格等静态事实，动作、运镜、节奏和音频只能作为生成建议。
- [ ] 视频仍可记录实际观察到的动作、环境动态、运镜、节奏和时间范围；音频不作为已观察事实。
- [ ] 每项结果能够标记为观察事实、复刻建议或未支持能力，并只在具体条目上表达不确定性及原因。
- [ ] 用户能够看到预处理和语义分析状态，以及鉴权、超时、网络和无效响应的区别化错误。
- [ ] 分析失败后保留本地预处理产物，并可从失败阶段重试而不重复不必要的解码与关键帧提取。
- [ ] 未配置或无法连接分析服务时阻止语义分析，但不破坏复刻项目已有数据。
