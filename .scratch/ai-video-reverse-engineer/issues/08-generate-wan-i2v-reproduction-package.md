# 08: 生成并下载 Wan2.2 14B I2V 复刻包

**What to build:** 让处于可复刻范围且适用 Wan2.2 14B I2V 的项目生成首个可执行工作流，并下载完整、可理解且不泄露密钥的复刻包。

**Blocked by:** 07/生成策略、Prompt 与智能匹配参数

**Status:** ready-for-agent

- [ ] 适用项目能够把当前分析、Prompt、控制素材和智能匹配参数转换为 Wan2.2 14B I2V Workflow。
- [ ] Workflow 生成前校验必要输入与参数，不生成明显缺少必需内容的伪可执行文件。
- [ ] 用户能够预览 Workflow 所依据的策略、参数、素材清单和生成时间。
- [ ] 用户能够下载包含关键帧、结构化分析、正负 Prompt、控制素材、推荐参数和 Workflow 的完整复刻包。
- [ ] 导出包包含可理解的内容清单和版本信息，不包含分析服务 API 密钥或系统安全存储内容。
- [ ] 没有连接本地 ComfyUI 时，生成和下载复刻包仍可完成。
- [ ] Workflow 与生成时的复刻方案版本建立关联，项目重新打开后仍可识别该版本。
- [ ] 生成或下载失败时保留已完成产物，并给出可重试操作。
