# 14: 生成本地深度控制素材并运行 Wan2.2 Fun Control

**What to build:** 从符合可复刻范围的参考视频在本地生成、检查和预览时间连续的相对深度控制素材，并产出可下载、可环境检查、可发送到本地 ComfyUI Queue 的 Wan2.2 Fun Control Workflow。

**Blocked by:** 06/校正并保留结构化分析, 07/按需生成策略提示词和智能匹配, 09/覆盖高级设置并管理 Workflow 新鲜度, 10/检查环境并发送到本地 ComfyUI

**Status:** wontfix

> 本票把已经实现的本地深度控制素材能力与已取消的应用内 ComfyUI Queue 混在一起，因此不再按原票实施。深度提取、质量检查、预览、持久化和候选工作流包由现有增量规格与验收记录维护；新的最终生成继续在外部完成。

- [ ] Apple Silicon、CUDA 和 CPU 路径遵循相同深度产物契约；M1 / 8GB 能在正式时长范围内完成提取而不因内存压力崩溃。
- [ ] 深度控制素材保持固定近远方向、时间轴、帧率和尺寸，不使用逐帧独立 min/max 归一化。
- [ ] 深度捕捉产物、模型版本、执行设备和阶段状态保存在当前复刻项目中，重启后可恢复。
- [ ] 用户能够同步预览参考视频与深度视频，并看到完整性、动态范围、闪烁、方向、边缘和时间对齐检查。
- [ ] `failed` 阻止正式工作流；`review_required` 必须由用户确认且执行记录标记为实验性。
- [ ] 通过质量门禁后能生成版本化 Wan2.2 Fun Control 深度 Workflow 和完整复刻包。
- [ ] 环境检查能报告该模板所需的 ComfyUI 版本、模型、节点和输入文件。
- [ ] 环境完整时能真实导入、Queue 并关联生成结果；环境不完整时仍可下载 Workflow。
- [ ] 替换参考视频会使旧深度捕捉失效，但不会删除已有生成运行的审计记录。
- [ ] 移动端只读，桌面端操作和预览满足既有可访问性规则。
