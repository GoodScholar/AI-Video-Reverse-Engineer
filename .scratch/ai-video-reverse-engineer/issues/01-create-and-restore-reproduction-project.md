# 01: 创建并恢复复刻项目

**What to build:** 让用户通过本地 Web 应用创建、命名、保存并重新打开复刻项目，并在开始工作前看到分析服务与本地 ComfyUI 的独立连接状态。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 用户能够创建带名称和创建时间的复刻项目，并进入该项目的初始页面。
- [x] 项目首页能够列出本地保存的最近复刻项目，并显示名称、缩略占位和最近更新时间。
- [x] 关闭并重新启动应用后，用户能够重新打开之前创建的复刻项目。
- [x] 分析服务和本地 ComfyUI 的状态分别展示，任一状态不可用都不会阻止创建项目。
- [x] 项目数据仅保存在本地，核心流程不要求账户、登录或云同步。
- [x] 空项目、首次启动和本地存储失败都有明确且可操作的界面状态。
- [x] 创建和打开项目可以通过键盘完成，并具有可见焦点。
