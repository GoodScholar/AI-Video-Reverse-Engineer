# 12: 提供移动端只读结果与完整可访问性

**What to build:** 让移动用户安全查看复刻项目、分析报告和输出，并确保桌面核心流程满足键盘、焦点、对比度和减少动态效果要求。

**Blocked by:** 08/生成并下载 Wan2.2 14B I2V 复刻包

**Status:** ready-for-agent

- [ ] 宽度不低于 1024px 时，用户能够完成项目、上传、分析、编辑、Workflow 生成和下载的完整流程。
- [ ] 移动宽度下可以查看复刻项目、结构化分析、Prompt、参数和输出状态。
- [ ] 移动宽度下不提供完整编辑、Workflow 生成或发送操作，并清楚说明需要桌面设备完成这些步骤。
- [ ] 核心桌面流程可以仅使用键盘完成，焦点顺序与三栏视觉顺序一致。
- [ ] 所有交互元素都有可见焦点、可理解名称和适合辅助技术的状态说明。
- [ ] 文字、控件与状态达到 WCAG 2.1 AA 所需对比度，错误、警告和成功不只依赖颜色表达。
- [ ] 分析进度、时间联动和执行状态在减少动态效果偏好下仍然清楚可用。
- [ ] 视频播放与时间选择提供键盘可用的替代操作，不要求精细指针操作。
- [ ] 桌面与移动查看状态都不会因内容较长、中文文本或错误信息而遮挡关键操作。
