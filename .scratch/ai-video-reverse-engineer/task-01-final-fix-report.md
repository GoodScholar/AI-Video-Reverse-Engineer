# 任务 01 最终集中修复报告

## RED → GREEN

- **项目 JSON 损坏**：原先 JSON 语法错误与非法时间戳均不能提供专用说明；现由 `Project` Pydantic 领域模型验证读取数据，错误返回“本地项目数据已损坏，请从备份恢复 projects.json，或将损坏文件移到其他位置后重新读取。”
- **并发创建**：原先八个并发 POST 会丢失项目（实测仅保留 3 个）；现由 `create_app` 内部的局部 `threading.Lock` 保护读-改-写，八个项目全部保留。
- **能力检测失败**：原先失败后仍显示旧状态，且没有重新检测入口；现先显示“检查中”，失败后两项独立显示“状态不可用”，并允许重新检测和离线创建项目。
- **前端错误与焦点**：原先首页吞掉后端损坏数据详情，取消创建后焦点落在页面主体；现展示后端 `detail`，并将焦点返还“新建复刻项目”。
- **对比度**：原先主按钮色与悬停色未受验证；现通过静态对比度脚本验证主按钮、悬停按钮、数量/时间元数据均至少为 4.5:1。
