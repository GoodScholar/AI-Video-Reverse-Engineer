# 01: 无损升级工作区模型并建立兼容边界

**What to build:** 让已有前置工作台项目在不丢失内容的前提下进入统一的 v2 模型。首次读取旧项目时，系统为镜头建立默认场景、稳定管理顺序、唯一镜头节点，以及由现有素材输入和流程步骤派生的只读关系；旧界面和已有调用在迁移期间仍能完成原来的读取、保存、运行和交付操作。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] v1 项目可读取为包含 Scene、Shot、WorkflowNode 和 WorkflowEdge 的 v2 内容快照，并派生一份独立修订的初始 CanvasLayout；每个制作镜头恰好对应一个规范 ShotNode。
- [ ] 迁移保留原有镜头和流程节点 ID、输入、参数、状态、错误、产物、结果候选及关联快照，现有节点运行和交付检查行为不回退。
- [ ] 默认场景和镜头 rank 的生成稳定且可重复；同一份 v1 数据重复迁移得到等价结果，不产生重复场景、节点或边。
- [ ] 读取旧项目时可以先返回兼容投影；第一次成功保存 v2 前保留可恢复的 v1 备份，迁移或校验失败时不覆盖原数据，并返回可理解的错误。
- [ ] 内容修订仍使用既有 CAS 约束，兼容调用通过同一 v2 事实来源工作，不形成并行的 v1/v2 数据副本。
- [ ] 自动化测试覆盖正常迁移、重复迁移、损坏输入、保存冲突和关键关联保留。
