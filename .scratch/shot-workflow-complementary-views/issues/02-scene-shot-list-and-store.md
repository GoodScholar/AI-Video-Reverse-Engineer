# 02: 用统一状态呈现场景化镜头列表

**What to build:** 让用户在一个按场景组织的镜头列表中浏览和编辑 v2 工作区。镜头卡片提供稳定的状态扫描，详细修改集中在检查器；列表、检查器和现有运行操作共享同一个规范化工作区状态，不再各自保存镜头副本。

**Blocked by:** 01 / 无损升级工作区模型并建立兼容边界

**Status:** ready-for-agent

- [ ] 镜头按 Scene 与 rank 稳定呈现，卡片显示缩略图、名称、计划时长、准备状态、候选数量和问题摘要。
- [ ] 长列表采用成熟虚拟化能力；滚动、展开场景和定位镜头时不丢失选择或未保存编辑。
- [ ] 工作区实体、顺序、选择、视图、布局和持久化状态通过一个规范化 store 提供，组件按对象标识订阅，不维护镜头副本。
- [ ] 镜头和现有流程节点的详细字段只在检查器编辑；保存、CAS 冲突、运行状态、结果候选和关联历史保持原有语义。
- [ ] 列表卡片只保留打开、复制、定位和更多等摘要操作，不复制检查器中的完整表单。
- [ ] 自动化测试覆盖场景分段、虚拟列表定位、编辑保存、未保存草稿保护、冲突恢复和现有节点运行回归。
