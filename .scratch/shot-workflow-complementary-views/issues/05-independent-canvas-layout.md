# 05: 独立保存画布布局

**What to build:** 让用户自由摆放镜头节点、折叠场景并恢复上次视口，同时保证这些空间调整不会改变镜头内容、管理顺序、流程依赖或结果有效性。布局拥有自己的冲突检测和撤销历史。

**Blocked by:** 03 / 提供可切换的只读镜头关系图

**Status:** ready-for-agent

- [ ] 节点位置、尺寸、场景折叠状态和各范围视口以独立 layout revision 保存和读取，不增加内容 revision。
- [ ] 拖动期间只更新当前交互状态，拖动结束时至多提交一次布局变更；刷新和重新进入项目后恢复相同布局。
- [ ] 同一布局的并发修改通过 CAS 返回明确冲突，不使用强制覆盖；内容保存与布局保存可以独立成功或失败。
- [ ] 布局变化不会修改 Shot.rank、Scene 归属、WorkflowEdge、节点 stale 状态、候选关联或交付快照。
- [ ] 节点移动和场景折叠支持布局级撤销/重做；选择、悬停、平移、缩放、聚焦和视口提交不进入撤销历史。
- [ ] 自动化测试覆盖布局恢复、单次提交、内容与布局修订隔离、冲突处理及撤销/重做。
