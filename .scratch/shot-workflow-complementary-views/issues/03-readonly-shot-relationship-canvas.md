# 03: 提供可切换的只读镜头关系图

**What to build:** 让用户在镜头列表之外切换到可缩放、可平移的关系图，查看场景、镜头以及已有素材和流程依赖。P0 只负责可靠呈现和导航，不允许通过画布新建连线或改变流程依赖。

**Blocked by:** 02 / 用统一状态呈现场景化镜头列表

**Status:** resolved

- [x] 使用成熟节点画布库呈现 Scene 框和 ShotNode，并能从一个镜头进入只读的现有素材与流程关系视图。
- [x] 画布节点和边由统一领域快照投影产生，画布库内部数组不成为业务数据来源。
- [x] 工作区提供“分屏、画布、列表”三种模式；桌面默认分屏，中等宽度使用检查器抽屉，窄屏默认列表并可切换到画布。
- [x] P0 不显示创建连线、编辑端口、任意分组、自动排布或最终 AI 视频生成入口。
- [x] 画布支持空格拖动平移、滚轮或触控板导航、适配当前范围和选中对象聚焦，并在文本输入获得焦点时停用画布快捷键。
- [x] 自动化和浏览器验证覆盖现有依赖投影、模式切换、项目切换、空工作区、桌面与窄屏布局。

## Answer

- 引入 `@xyflow/react`，由规范化工作区快照投影项目 Scene / Shot 关系及单镜头素材、流程依赖；XYFlow 仅负责只读呈现和视口交互。
- 新增分屏、画布、列表三种模式和响应式检查器；1280px 三栏、1100px 抽屉、800px 默认列表均通过真实浏览器验收。
- 支持适配范围、聚焦选择、滚轮平移、空格拖动和文本输入快捷键隔离；不可见只读 Handle 仅用于绘制既有边，不开放连接编辑。
- 自动化覆盖投影、状态语义、模式与项目切换、空态和现有工作区回归；双轴审查最终均无发现。
