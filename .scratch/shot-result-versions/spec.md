# 镜头结果候选版本

已授权继续下一项优化。服务器保留每镜候选列表，采用指针沿用 resultAssetId；上传新结果自动采用但保留旧候选，选择已有视频也登记候选，取消采用不删除历史。旧单结果项目兼容为待复查候选。

候选关联时记录方案内容摘要。摘要包括需求、提示词、计划时长、参考资产和有序步骤参数，排除标题、当前采用指针、任务状态与媒体产物运行状态。当前方案不同则提示复查。人工“已按当前方案检查”通过专用 CAS 接口记录，普通 PUT 不接受伪造/删除服务器历史或检查状态。仅提示，不强制替换旧剪辑、不阻断导入。

交付包包含全部候选视频、采用状态和人工检查状态。新候选最多 100 个/镜头，与现有素材绑定数量量级一致。没有候选删除、自动评分或真实模型验收；不新增下载。

验证：多次上传、切回旧候选、取消采用、旧数据、变更失效、伪造状态、CAS、包中实际文件；前端操作和浏览器桌面/窄屏验证。
