# 逐镜头参考与结果对比

下一项已授权改进：在镜头结果区内提供并排视频、共同播放/暂停、镜头内时间定位、按选择帧率步进。复用素材 URL 与浏览器视频能力，不安装依赖。

明确参考：唯一直接引用视频的截取节点可默认给出参考与起止范围；否则仅在绑定的视频唯一时选定参考，仍允许选择项目视频及调整对比范围。多个候选不猜测。结果使用当前镜头 resultAssetId；切换镜头/结果后停止旧播放器并重新初始化。

仅在两侧媒体元数据加载后允许播放。范围取计划时长、参考选段和两侧实际可播放时长交集；短结果明确提示。结果从零秒对应参考选段起点。只有一侧声音，支持选择参考/结果/静音。播放失败、媒体错误、缓冲中断可见反馈；卸载停止播放和同步循环。

对比参数为临时查看设置，不改变镜头、结果或剪辑。帧按钮按所选 FPS 的时间间隔定位，不宣称变帧率视频解码级逐帧精度。

验证：参考偏移、短素材边界、播放失败/停止、选择歧义、切换素材，以及浏览器桌面/窄屏布局与真实视频同步。
