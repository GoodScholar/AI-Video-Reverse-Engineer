# 05: 关闭旧最终生成提交入口

**What to build:** 统一落实当前 ADR 规定的外部最终生成边界，关闭所有仍能从旧接口或旧界面创建、提交或启动最终 AI 视频生成的行为。相关写操作必须返回一致且稳定的停用响应，并说明该能力当前不可用；既有历史记录读取、已有结果查看与导出以及外部执行所需的准备性数据不得被破坏。该票据只消除范围冲突，不删除历史数据，也不恢复或替代最终生成能力。

**Blocked by:** None (can start immediately).

Status: resolved

- [x] 枚举正式与旧路径中所有可能创建、提交、排队或重试最终 AI 视频生成的入口，并形成可审计清单。
- [x] 所有上述写入口统一返回稳定的停用响应，且不会创建运行记录、调用外部生成服务或产生部分副作用。
- [x] 旧界面和正式界面均不再显示或触发最终 AI 视频生成动作，并能向用户清楚说明当前边界。
- [x] 既有生成历史、状态、输出和错误仍可只读查看，已有结果仍可按原边界回填、查看或导出。
- [x] 工作流、制作准备和外部执行所需数据的导出能力保持可用，不被误判为最终生成提交。
- [x] 自动化验证逐项覆盖入口清单，证明每个写入口均已关闭，同时历史读取和允许的导出路径不回归。
- [x] 核对实现行为与现行 ADR 及范围冻结基线一致，不保留能够绕过正式界面的隐蔽提交路径。
