# 01: 核实试点商品与素材使用边界

**What to build:** 从正式项目入口建立或整理一个可用于 P0 验收的真实商品试点，逐项核实商品名称、SKU、包装、规格、卖点和禁用表达，并让每项入选素材都有可追溯的来源、取得方式与本次使用范围。优先核实现有“大窑果味汽水”资料；若现有资料或“20香”图片无法确认对应商品及使用范围，则用自有或明确授权的真实商品素材替换后再继续。最终结果必须能直接支持创作简报和后续脚本生成，不以口头假设、文件名或网络可访问性代替事实与使用依据。

**Blocked by:** None (can start immediately).
