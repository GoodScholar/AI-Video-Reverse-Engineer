# 候选与渲染历史清理

仅本地，不下载依赖，不涉及AI功能。保留删除操作的明确预览与确认。
- 未采用候选可从指定镜头历史移除，同时移除其人工检查记录；当前采用结果不可移除。预计释放0字节，不删除素材、其他镜头或时间线引用。
- 已结束渲染记录可清理；排队/运行任务以及取消后尚未退出的worker均不可清理。
- 清理预览显示影响范围、文件数量与预计释放字节数；确认后重查状态与版本。
- 清理指定run的输出文件和独立源副本，保留原素材/时间线编排/其他输出；安全路径检查拒绝symlink。
- 文件先暂存，元数据写入失败则恢复文件；元数据成功后物理清理若失败，明确报告残留，不声称空间已全部释放。
- 清理使用revision校验，成功递增对应工作台revision，防止旧回包或并发保存复活历史。
- 源素材删除保持独立，并使用现有引用保护。UI草稿未保存时不开放历史清理。
