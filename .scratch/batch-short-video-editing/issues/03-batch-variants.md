# 03：批量生成并筛选短视频变体

**What to build:** 交付人员为一个任务提交 5–20 条已确认脚本或卖点组合，工作台批量编排并集中显示各变体的预览、内容依据和进度；一条失败时仍能查看、修改和重试其他变体。

**Blocked by:** 02：按卖点与脚本推荐一条变体。

- [x] 用户能指定目标数量并提交符合上限的批量任务，每条变体都有独立脚本、卖点、时间线、版本和预览结果。
- [x] 批量列表能比较各变体的镜头取舍及对应卖点；目标数量超限或素材不足时给出可行动提示。
- [x] 生成与预览有有限并发及逐条状态；单条失败、取消、重试或应用重启不覆盖其他变体的已保存内容和可用结果。
- [x] 对一条变体的人工编辑不会静默传播到其他变体；重新生成不会覆盖已修改的版本。
- [x] 通过项目 API 与工作台验证至少两条不同脚本的真实预览、局部失败及重试；使用测试负载验证 5–20 条的状态管理，不以自动测试宣称营销效果。
