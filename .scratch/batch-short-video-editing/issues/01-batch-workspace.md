# 01：建立批量任务并完成一条变体

**What to build:** 交付人员在现有项目中创建批量混剪任务，录入卖点和已确认脚本，从多段项目素材手动编排一条独立短视频变体，保存、修改并播放该变体的竖版预览。原有项目时间线与其他任务不受影响。

**Blocked by:** None (can start immediately).

- [x] 批量任务和变体有稳定标识、独立持久化状态及版本；重新打开项目后仍能看到已保存脚本、素材引用和镜头顺序。
- [x] 用户可从项目素材选择片段并修改镜头顺序、入出点及现有音频参数；非法或缺失素材给出明确错误，沿用现有单条时间线限制。
- [x] 用户可生成并播放对应已保存版本的低清预览；未保存编辑不会冒充已渲染内容，失败不会覆盖旧预览。
- [x] 新任务不改写原项目时间线；另一批量任务或变体的保存和预览不覆盖本条结果。
- [x] 通过项目 API、工作台操作与真实短素材渲染验证以上路径；测试版本冲突和项目隔离。
