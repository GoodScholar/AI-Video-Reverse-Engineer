# 05：逐条审核并使旧批准失效

**What to build:** 审核人员在批量任务中逐条查看当前预览、卖点、脚本、素材和字幕，对变体通过或退回并记录原因；任何影响成片的修改都使该条旧批准失效。

**Blocked by:** 01：建立批量任务并完成一条变体；04：识别、编辑并烧录变体字幕。

- [x] 审核界面显示预览和其对应的内容版本，支持逐条通过或退回及原因记录。
- [x] 脚本、片段、字幕或输出设置变化后，旧审核不能作为当前版本批准；其他未改动变体的批准保持有效。
- [x] 审核依据的预览过期或失败时不能批准当前版本；重新预览后可以再次审核。
- [x] 项目重开后审核历史和当前有效状态仍可区分，不能通过编辑请求伪造当前批准。
- [x] 用项目 API 和工作台验证版本失效、跨变体隔离、退回与重新批准路径。

## Comments

范围和阶段假设见 [规格](../spec.md)。批量导出门禁由 06 接入。

工作台与变体保存接口统一使用 720×1280、30fps 预设；设置或时间线快照与审核依据不一致时旧审核失效。审核历史由服务端保存，当前状态按版本及已审预览快照计算。第 05 项完成时的测试：后端 1211 通过、9 跳过，前端 324 通过，构建通过；第 06 项进一步收紧了固定预设及快照校验。
