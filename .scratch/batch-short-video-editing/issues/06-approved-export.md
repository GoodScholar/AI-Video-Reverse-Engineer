# 06：仅导出已批准变体并保留交付记录

**What to build:** 交付人员从批量任务选择当前版本审核通过的变体，生成统一竖版成片，查看逐条导出状态，并回溯每条交付结果对应的脚本、素材、字幕和审核版本。

**Blocked by:** 03：批量生成并筛选短视频变体；05：逐条审核并使旧批准失效。

- [x] 未通过审核、审核版本过期或预览版本过期的变体不能进入最终批量导出；仅批准的变体可被选择。
- [x] 成片使用界面明示的统一竖版预设并烧录当前批准版本的字幕，交付文件可播放。
- [x] 列表逐条报告排队、运行、成功、失败或取消；单条失败和重试不覆盖其他已完成成片或已批准内容。
- [x] 每条成片保留其不可变输入快照及脚本、卖点、素材、时间线、字幕和审核版本关联；原素材缺失时历史记录仍可读，但禁止重新渲染受影响版本。
- [x] 通过真实 FFmpeg 输出和项目 API 验证批准门禁、竖版尺寸、字幕可见性、局部失败、重启后的状态与历史回溯。

## Comments

范围和阶段假设见 [规格](../spec.md)。完成本票据后按规格进行端到端人工内容验收；相关内容质量不能由流程测试代替。

导出从已批准预览的素材快照复制文件；提交时校验原素材仍存在且内容一致，避免审核后替换素材却交付新画面。交付记录保存脚本、卖点、素材清单、时间线、字幕、审核和预览版本。固定预设为 720×1280、30fps。后端全套 1213 通过、9 跳过；前端全套 325 通过；构建通过。真实 FFmpeg 测试检查尺寸、帧率、字幕文件及画面字幕；排队任务重启、失败隔离和重试均由项目 API 测试覆盖。

端到端人工样例：用五段不同颜色且名称对应脚本的真实视频批量编排，五条均匹配到对应镜头；其中两条完成预览、审核和导出。逐帧查看到“快速启动”为红色画面、“防水测试”为蓝色画面，且两条中文字幕正确出现。真实客户素材的营销内容质量仍需在实际交付时评估。
