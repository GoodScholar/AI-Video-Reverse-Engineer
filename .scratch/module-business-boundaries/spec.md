# 内容项目与模块业务边界收口

Status: resolved
Type: task

## Problem Statement

现有产品已经同时承载参考视频复刻、商品内容创作、项目素材、时间线、批量混剪、审核与交付，但历史规格仍把顶层工作单元称为“复刻项目”，并保留应用内提交 ComfyUI 的旧任务。默认内容工作室、旧版兼容工作台和若干后端模块由此使用不同的产品边界，后续开发容易继续实现互相冲突的流程。

## Solution

以“内容项目”作为唯一顶层工作单元；参考复刻和商品视频制作是内容项目中的两条工作流。参考素材、参考镜头段、制作镜头、短视频变体、渲染运行、审核版本和交付记录分别拥有自己的生命周期，以稳定标识关联，不用一个项目状态代表全部流程。

最终 AI 视频生成继续由外部工具完成。应用负责分析、素材与控制准备、复刻方案、候选工作流导出、外部结果导入、本地剪辑、渲染、审核和交付；历史 ComfyUI 运行记录保留，但不重新开放新的最终生成提交。

## Authoritative module ownership

| 模块 | 拥有的业务对象与规则 | 不拥有 |
| --- | --- | --- |
| 项目工作区 | 内容项目身份、项目素材、当前参考素材、派生关系与工作流入口 | 时间线剪辑决定、审核结论 |
| 内容简报 | 商品事实、素材授权范围、脚本候选与确认版本 | 配音运行、渲染完成状态 |
| 制作计划 | 参考镜头段、制作镜头、镜头步骤、结果候选与采用关系 | 外部生成是否真实消费了输入 |
| 编辑序列 | 时间线、短视频变体、画布、字幕、配音绑定与内容快照 | 外部供应商协议、审核通过决定 |
| 渲染运行 | 冻结编辑输入、预览/正式用途、执行状态与真实媒体属性 | 修改脚本、静默批准成片 |
| 审核交付 | 审核版本、意见、失效原因、批准版本与交付历史 | 重写历史产物、替用户修改内容 |
| 外部适配与运行基础设施 | 分析、生成工具、TTS 等协议适配及运行恢复 | 商品事实、镜头采用、审核结论 |

## Business commands

- `确认脚本`：确认当前内容版本，不生成配音，不审核成片。
- `采用镜头结果`：把候选结果关联到制作镜头，不证明外部模型使用了计划输入。
- `保存短视频变体`：保存时间线、字幕、画布和配音绑定的新内容版本，不修改项目素材原件。
- `生成预览`：冻结当前编辑输入并产生可审核媒体，不自动批准。
- `审核当前版本`：把意见与决定绑定到内容快照及预览产物。
- `导出已通过版本`：只消费仍然有效的审核版本，不读取后来改变的项目默认设置。

## Compatibility policy

- 默认入口为内容工作室，新建的是内容项目。
- `?workspace=legacy` 是旧版复刻工作台，只为历史复刻流程提供兼容访问；不再接收新产品功能。
- 旧版工作台可以继续读取和修改其原有数据，但不能改变最终生成在外部完成的边界。
- 历史规格和任务保留作为决策记录；与 ADR 0007 冲突的应用内生成提交需求标记为 `wontfix`。

## Acceptance criteria

- `CONTEXT.md` 对内容项目、参考镜头段、制作镜头、渲染运行和审核版本给出唯一含义。
- ADR 明确顶层项目、工作流和运行基础设施的所有权边界。
- 历史总规格清楚标示已被增量规格与 ADR 取代的范围；冲突任务不再处于 `ready-for-agent`。
- 默认界面将兼容入口明确标为旧版复刻工作台，README 与设计规范使用相同措辞。
- 现有最终生成 `410 final_generation_disabled` 契约继续通过，不删除历史记录或离线工作流导出。

## Out of scope

- 本轮不拆分 `main.py`、`batch_editing_api.py` 或迁移存储格式。
- 本轮不新增通用工作流引擎、事件总线、微服务或外部生成供应商。
- 本轮不删除历史运行代码、历史数据或兼容工作台。
- 内容制作阶段投影、批量制作深模块和统一运行生命周期分别进入后续任务。

## Evidence

外部边界模式及本项目推论见 [模块业务逻辑对照研究](../../docs/research/module-business-logic-benchmark-2026-09-27.md)。

## Result

已统一内容项目、参考镜头段、制作镜头、渲染运行和审核版本，记录模块所有权 ADR，关闭与外部最终生成边界冲突的历史任务，并将默认界面的历史入口明确标为“旧版复刻工作台（兼容）”。后续阶段投影、批量制作模块和运行生命周期已拆为独立任务。
