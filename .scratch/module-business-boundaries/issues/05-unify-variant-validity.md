# 05: 统一短视频变体的版本有效性

Status: resolved
Type: task
Blocked by: 04

## What to build

深化现有 `batch_production` 应用模块，由它统一派生短视频变体的配音、预览、审核和交付有效性。内容工作流投影与 HTTP 适配器只消费目的明确的结论，不再分别解释版本、冻结快照和运行身份；现有 API、状态文件和历史记录保持兼容。

## Acceptance criteria

- [x] `batch_production` 提供一个只读变体生命周期视图，分别表达配音、当前预览、当前审核、当前交付及稳定失效原因，不提供含义模糊的总括 `is_current`。
- [x] 脚本改变会使配音失效；只修改画面轨道、输出设置或字幕时，已完成配音仍可使用，但旧预览、审核和交付失效。
- [x] 审核绑定具体预览产物；相同编辑输入重新渲染后，旧审核保留用于追溯但不能批准新预览。
- [x] 导出复用绑定当前变体版本和具体预览 ID；同一预览重新批准可以复用，新预览不得复用旧预览的导出。
- [x] 内容制作阶段只反映当前有效链路，历史批准或交付不能让已失效变体继续显示 `approved` 或 `delivered`。
- [x] 批量预览复用、审核和导出命令通过 `batch_production` 的窄接口判断；HTTP 层不再直接比较三类 revision。
- [x] 旧状态中缺失的兼容字段仍按现有规则读取；不新增依赖，不迁移存储，不改变 HTTP 结构或错误码。

## Answer

已在 `batch_production` 中建立统一的只读生命周期视图，并让审核、导出复用、批量预览复用和内容工作流投影消费该视图或目的明确的窄接口。配音只随脚本内容失效；预览同时校验三类修订、冻结画面输入和字幕；审核与交付分别绑定具体预览，且同一预览重新批准仍可复用已完成导出。

验证结果：后端全量测试 1313 passed、10 skipped；前端全量测试 383 passed；前端生产构建通过；Python 编译与 `git diff --check` 通过。固定基线 `585b86a` 的双轴审查未发现标准硬性违规；规格审查发现并修复了完成预览复用遗漏冻结输入校验的问题，修复后相关 23 项测试通过。标准审查另记录一项非阻断的重复谓词维护性建议，本票据不扩大范围处理。
