# 04: 统一可恢复运行生命周期

Status: resolved
Type: task
Blocked by: 03

## What to build

提取内部可恢复运行契约，统一排队、运行、完成、失败、取消、重启恢复、冻结输入与结果记录；本地计算队列和外部执行适配分别实现所需能力，不把业务审核或采用决定放入运行基础设施。

## Acceptance criteria

- [x] 本地运行与历史外部运行共享稳定的状态词、输入快照和恢复规则，同时允许能力差异。
- [x] 状态不确定只用于确实可能已提交的外部运行，本地任务不伪造该状态。
- [x] 重启恢复、取消和迟到结果不会覆盖更新的业务版本。
- [x] 运行完成只产生结果，不自动采用、批准或交付。
- [x] 各业务模块通过窄接口提交与读取运行，不直接复制队列恢复逻辑。

## Answer

新增 `durable_runs` 内部运行契约，统一本地与历史外部运行的稳定状态、冻结输入指纹、状态转换、重启恢复和结果边界。本地运行统一进入单工作线程计算队列，预处理、深度捕捉和语义分析通过窄适配器复用该执行器；各业务模块使用共享策略处理排队、运行、失败、取消与恢复。外部运行仅在已经可能提交时进入 `unknown`，提交前失败保持 `failed`。

完成结果只记录执行产物，并拒绝携带采用、审核或交付决定；取消后的迟到结果及输入版本变化后的迟到结果均被拒绝，现有 HTTP 契约和历史状态格式保持兼容。
