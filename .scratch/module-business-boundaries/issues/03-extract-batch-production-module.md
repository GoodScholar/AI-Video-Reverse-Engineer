# 03: 提取批量制作业务模块

Status: resolved
Type: task
Blocked by: 02

## What to build

从 `batch_editing_api.py` 提取拥有批量任务、短视频变体、内容版本、预览、审核与交付规则的应用模块。HTTP 路由只负责请求校验和错误翻译，现有接口与存储格式保持兼容。

## Acceptance criteria

- [x] 应用模块提供明确命令：创建批次、保存变体、提交预览、审核当前版本、导出已通过版本。
- [x] 每个命令的前置条件、版本更新和失效规则由同一模块拥有，不散落在路由处理器中。
- [x] 预览与正式导出消费同一种冻结编辑快照，实际媒体属性由渲染结果记录。
- [x] 路由层不直接决定审核通过、版本是否过期或哪些作品可交付。
- [x] HTTP 契约、历史状态文件和现有用户流程保持兼容。

## Answer

新增 `batch_production` 应用模块，统一拥有普通批次与 AIGC 交接、内容/字幕/配音版本、变体保存、冻结预览、当前版本审核及已批准导出的业务规则。HTTP 路由保留请求校验、持久化、文件与队列适配；预览和正式导出复用审核通过的冻结编辑快照，真实渲染会记录宽高、帧率与时长。

验证：后端 `1289 passed, 10 skipped`；前端 `383 passed`；TypeScript 与 Vite 生产构建通过。双轴代码审查最终无规范或规格遗留问题。
