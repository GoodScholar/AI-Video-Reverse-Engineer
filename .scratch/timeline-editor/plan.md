# 实施计划

1. 按 spec 固定接口分工：FFmpeg 合成引擎、时间线界面、主控存储/API。分别先写核心行为失败测试再实现。
2. 主控挂载服务与剪辑导航，补安全来源/版本/任务生命周期测试。
3. 真实媒体验收：两色画面顺序、视频层级、静音与叠加音轨、截取/倍速/淡入淡出、取消/输出时长。
4. 前端交互测试、构建、真实浏览器桌面和窄屏检查、独立审查及修复。

Ruling: 用户新需求扩展旧 ADR 0007 的“只交付前置包”边界，允许 FFmpeg 本地剪辑混音导出；AI最终生成继续关闭。
Ruling: 不安装大型编辑器依赖，使用既有React/CSS和FFmpeg，准确渲染预览以保证与导出一致。

## 用户补充约束

- 下载或安装任何依赖、模型和权重前必须取得用户明确同意，仅使用本机现有环境。
- 产品主线是参考视频复刻与白膜视频复刻。剪辑和音频模块仅作为复刻片段、节奏与音轨处理及交付的辅助能力，不继续扩展通用非线性编辑器范围。
- “白膜视频”是否指相对深度或无材质三维动画，正在向用户核实；不得提前把两者视为同一种控制输入。
- 用户已确认灰度深度视频与三维白模视频两种都需支持。两者是不同参考/控制类型，现有深度提取不代表已支持两条完整复刻链路。
