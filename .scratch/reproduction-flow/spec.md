# 三类输入与复刻制作闭环

本轮连接已有本地功能，不增加模型推理、下载或云调用。
- brief.inputKind 保存 reference_video / depth_video / white_model_video，旧项目默认参考视频。白模指已经渲染的视频，不接受三维工程文件。
- 常驻流程提示显示素材、拆镜头、控制准备、导出、结果回填和剪辑的真实条件。跳转已存在工具面板；灰度深度输入不默认再次估深。
- 生成结果以 shot.resultAssetId 独立关联，不能替换分析参考。上传结果仅接受视频，采用项目 revision CAS，引用必须是本项目资产。
- 方案包记录输入类别及逐镜结果，明确模型兼容与效果仍需外部验收。
- 时间线导入用时间线与工作台双版本校验，按计划时长从结果视频零秒截取；较短结果拒绝，不自动变速或补帧。追加独立轨道到已有时间线尾端，同一工作台版本重复导入不复制。
- 前端不覆盖未保存时间线草稿；需先保存或处理草稿，再导入。

## 实施与验证
1. 后端输入分类/逐镜结果持久化、校验及交付包；测试兼容、类型、版本隔离。
2. 时间线追加接口；测试排序、时长、冲突、非覆盖和重复导入。
3. 入口、过程指引、逐镜结果回填及剪辑按钮；前端回归、构建及桌面/窄屏浏览器验证。
