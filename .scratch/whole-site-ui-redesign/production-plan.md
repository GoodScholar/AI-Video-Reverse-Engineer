# 全站正式界面迁入计划

用户已接受并要求按全站视觉稿实施。直接在当前工作区沿用既有真实 API，不新增依赖，不自动提交；数字人保持暂停。

## 实施与验证

1. AigcCreator 增加引导呈现：资料与素材同页、生成按钮串联保存与发送预览、逐条脚本编辑/保存/确认后交接。原组件默认调用保持兼容。验证：失败保存不发送、确认发送才生成、修改候选必须保存新版本才能确认。
2. BatchEditor 增加选声/审片/精修呈现，同一实例保留草稿。自动读取已有音色目录，配音完成后提供批量真实预览，审片保留版本校验与导出限制。验证：切换呈现保留编辑、选择音色不自动计算、未完成/旧版本无法审核导出。
3. 正式 ContentStudioApp 和项目制作工作区：真实项目列表/创建/恢复、统一全站导航、素材/复刻/工具/设置/备份接入已有模块，移除商品主流程中的复刻阻塞提示。原 App 作为兼容入口保留。验证：项目读写错误、跨页草稿、项目隔离、旧功能回归。
4. 复用已批准布局和媒体呈现规范；实际项目素材承担缩略图与预览，不把公共演示咖啡当作真实项目数据。验证：现有前端测试、构建、桌面/窄屏真实浏览器及独立审查。
5. README 和 design.md 同步正式入口、实际接入与剩余边界；无客户素材不宣称完整客户验收。
