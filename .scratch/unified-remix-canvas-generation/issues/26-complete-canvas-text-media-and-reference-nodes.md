# 26: 完成画布文本、媒体、引用与处理节点

**What to build:** 在类型化画布上交付文本、图片、视频、音频、配置、组和既有本地处理节点，支持稳定多引用排序、富文本提及、预览/下载/替换/入库、图片裁切切分、蒙版、普通缩放与超分区分、角度/3D 导演参考及提示词反推来源。

**Blocked by:** 03: 统一项目素材结果安装与版本失效传播; 24: 分离画布业务节点与视图并建立执行 DAG

**Status:** ready-for-agent

## Scope

- 文本节点支持编辑、稳定提及和明确结果引用，不以普通文本框代替完整数据关系。
- 图片、视频和音频节点复用项目素材与现有安全媒体处理，所有加工结果形成新素材版本。
- 多引用保持顺序、来源和删除语义；替换当前素材使依赖下游过期。
- 本地裁切/缩放与模型编辑/超分明确分开，未知模型能力不展示。

## Source reuse prerequisite

- 阅读 Toonflow 和 basketikun/infinite-canvas 固定提交中的文本、媒体、引用、生成记录和节点插件源码。
- 阅读项目现有图片/视频/音频处理、蒙版、超分、提示词和素材安装源码；优先复用真实处理服务。

## Acceptance criteria

- [ ] 文本编辑、富文本稳定提及和多引用排序在刷新后保持正确来源。
- [ ] 图片、视频、音频可上传、预览、替换、下载和输出，结果使用项目素材身份。
- [ ] 图片裁切/切分产生可追溯新素材，撤销后原素材仍可使用。
- [ ] 蒙版可绘制、编辑和保存；没有真实模型能力时不伪造局部生成结果。
- [ ] 普通缩放与模型超分在文案、运行、来源和结果上明确区分。
- [ ] 角度/3D 导演等参考节点保存参数、预览和处理来源；提示词反推绑定明确素材版本。
- [ ] 配置、组和既有处理节点使用受控注册表及完整端口类型。

## Verification evidence

- 领域/API/UI 测试覆盖多引用、提及、替换、过期、加工入库和撤销。
- 使用真实图片、视频和音频完成处理、预览、下载与下游引用。
- E1 记录每类复用节点的固定来源、许可和适配边界。

## Out of scope

- 真实文本/图片/视频生成；由票据 27 完成。
- 自研通用图像编辑器或 3D 引擎。
