# 17: 交付高光候选、去重与 Top N 纵向切片

**What to build:** 从已完成的长视频绝对时码转录生成可审计高光候选，贯通模型提交、候选解析、评分、证据展示、版本化去重、确定性排序和 Top N 保存；无效响应、超时、无有效高光和取消均有明确状态。

**Blocked by:** 16: 交付 faster-whisper 长视频绝对时码转录

**Status:** ready-for-agent

## Scope

- 候选保存稳定身份、全片起止、评分维度、总分、选择理由、转录证据、模型/提示版本和来源分块。
- 默认去重兼容参考实现“候选与已保留项重叠超过候选自身时长 50% 时抑制低分项”，同时补齐对称重叠、边界和确定性排序。
- 模型输出先做结构、范围和证据校验；无效结果按明确次数重试，最终失败不产生伪候选。
- UI 能回放候选源区间、查看评分和理由、选择或排除 Top N。

## Source reuse prerequisite

- 阅读 Anil 固定提交中的高光提示、分块、解析、去重和排序源码，并核实其声明的 ViralVadoo 来源与授权链。
- 来源未确认时不得复制相关代码；可以在记录原因后按规格行为自行实现并保留对照测试。

## Acceptance criteria

- [ ] 候选所有时间都为全片绝对坐标且位于媒体范围内，第二/第三块不会错位。
- [ ] 每个候选展示稳定身份、评分、理由、转录证据和来源块，并可定位播放。
- [ ] 非对称 50% 规则、对称重叠、同分、边界相接和跨块重复具有确定结果。
- [ ] 无效 JSON、越界时码、空候选、超时、取消和无有效高光均有明确可重试/失败状态。
- [ ] Top N 保存请求数、候选数和选中身份，不以模型返回顺序作为业务身份。
- [ ] 提示或模型版本变化使旧候选明确过期但仍可追溯。

## Verification evidence

- E2 固定转录夹具覆盖解析、越界、重叠、同分、跨块、无效响应和确定性。
- E3 对至少一份授权真实长视频生成候选并回放核对来源区间。
- E4 人工记录高光召回、采用和未采用原因，不与脚本混剪指标混用。

## Out of scope

- 竖屏裁切、编辑序列和最终导出。
- 把 LLM 评分宣传为训练好的传播预测模型。
