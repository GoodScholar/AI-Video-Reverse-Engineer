# 32: 验收画布驱动生成真实金标闭环

**What to build:** 使用真实 Provider 完成第三条最高测试接缝：画布文本节点产生可采用输出，依次驱动真实图片和真实视频生成，结果入库为项目素材并用于下游续创或混剪，最终进入预览和人工审核。

**Blocked by:** 27: 从画布执行文本图片视频生成; 28: 从画布委托混剪并交付受控 AgentAction

**Status:** ready-for-agent

## Scope

- 从一个保存的画布修订开始，冻结文本、图片、视频节点的有序输入、能力和配置快照。
- 文本、图片、视频分别使用已验证真实 Provider；媒体结果通过项目素材而非临时路径传递。
- 至少一次结果用于下游续创，至少一次交给 `RemixEngine` 或 Timeline 形成可播放预览。
- 覆盖取消、失败/未知、迟到结果、重试、重启恢复和上游变化导致下游过期。

## Source reuse prerequisite

- 汇总 Toonflow/Infinite Canvas 参考、统一生成适配器、项目素材、混剪与预览审核的源码/许可记录。
- 只调用正式 `CanvasEngine`、`GenerationService` 和 `RemixEngine` 接缝，不使用直接 Provider 或临时文件旁路。

## Acceptance criteria

- [ ] 画布文本节点通过真实 Provider 生成不可变输出，并经明确采用进入下游。
- [ ] 真实图片生成使用稳定文本/图片引用，结果入库并可预览、下载和继续引用。
- [ ] 真实视频生成使用适用的文本、图片或首尾帧，异步恢复后入库并可播放。
- [ ] 生成媒体用于下游续创或混剪，并形成现有预览和人工审核记录。
- [ ] 上游变化或切换结果使下游过期且不自动重复计费提交。
- [ ] 取消、未知、迟到、重试和重启恢复具有真实可观察证据。
- [ ] X11–X18 及相关 C/G/A 项获得 E3/E4 证据。

## Verification evidence

- 真实 Provider 运行、画布修订、依赖子图、项目素材、下游运行、预览和审核记录。
- E4 人工检查 Toonflow 操作、图片/视频质量、来源关系和过期提示。
- 模拟服务和静态截图只能补充合同证据，不能替代本票。

## Out of scope

- 自主长期 Agent 循环、自动批准或多人实时协作。
- 绕过项目素材直接把远端 URL 接入下游。
