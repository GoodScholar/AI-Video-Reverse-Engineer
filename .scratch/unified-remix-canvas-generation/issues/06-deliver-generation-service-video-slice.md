# 06: 交付统一视频生成纵向切片

**What to build:** 在统一生成门面上接入一个异步视频适配器，让用户按模型真实能力提交文生视频或图生视频请求，持久化远端任务身份，重启后继续查询，表达真实取消语义，并把成功视频安装为可供画布、混剪和 Timeline 使用的项目素材。

**Blocked by:** 04: 交付统一文本生成纵向切片

**Status:** resolved

## Scope

- 为视频模态增加文生视频、图生视频、首帧、尾帧、多参考、时长、比例、分辨率和音频能力描述。
- 异步运行保存远端任务身份、最近确认状态、轮询/回调游标和取消结果。
- 界面区分本地停止、远端已取消、取消不支持、状态未知、迟到成功和计费未知。
- 成功媒体通过现有项目素材链安装，并能被下游真实读取。

## Source reuse prerequisite

- 先阅读现有视频生成候选、运行恢复、媒体下载/校验、素材入库和 Timeline 引用源码。
- 以所选 Provider 官方资料和真实探针冻结能力，不从营销文案或其他 Provider 推断参数。

## Acceptance criteria

- [x] 文生视频和图生视频入口只显示适配器声明且经服务端校验的能力组合。
- [x] 首帧、尾帧、多参考、时长、比例、分辨率和音频非法组合在提交前可见并被服务端拒绝。
- [x] 远端任务身份持久化，服务重启和页面刷新后继续查询且不重复提交。
- [x] 本地停止不冒充远端取消；取消不支持、未知和迟到结果均有确定状态。
- [x] 成功视频校验后安装为不可变项目素材，可预览并被画布、混剪或 Timeline 引用。
- [x] 下载失败、媒体损坏、单项失败和重试不会覆盖历史或产生重复计费请求。

## Verification evidence

- 协议假服务覆盖异步提交、轮询、取消支持/不支持、未知、迟到、重启和媒体损坏。
- 使用真实视频夹具验证下载、探测、入库、预览和下游引用。
- 真正 Provider 的通过证据由票据 08 完成。

## Out of scope

- 自研视频模型、自动模型路由和 ComfyUI Workflow。
- 替换现有 FFmpeg 渲染器。
