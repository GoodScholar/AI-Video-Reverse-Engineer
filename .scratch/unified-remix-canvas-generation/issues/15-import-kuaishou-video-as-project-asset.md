# 15: 真实导入快手视频为项目素材

**What to build:** 使用独立 `KuaishouSourceAdapter` 或另一个固定版本、许可与真实下载均验证的实现，把用户有权使用的快手公开页面、正常分享链接或合法会话可访问视频导入项目素材；不得把通用下载器的一次偶然成功当作正式支持。

**Blocked by:** 10: 建立统一视频来源合同并贯通本地导入

**Status:** ready-for-agent

## Scope

- 独立识别快手标准页面、分享文本和短链，限制重定向并分类平台错误。
- 权利确认后完成真实下载、媒体校验、哈希、来源登记、入库和预览。
- 合法会话只进入系统安全存储；记录适配器版本、最近验证时间与四态状态。

## Source reuse prerequisite

- 在实现前定位并阅读候选快手适配器的实际解析、下载、会话与错误处理源码，冻结提交和许可证。
- 若无许可清晰且可真实验证的实现，记录具体原因后进行最小自研适配；不得复制来源不清代码。

## Acceptance criteria

- [ ] 快手 URL 和分享短链由独立适配器识别，非目标或危险重定向被拒绝。
- [ ] 权利确认和合法会话规则生效，不自动登录、扫码或绕过私密/会员控制。
- [ ] 下载、探测、哈希、来源登记和项目素材安装形成原子结果。
- [ ] 需要登录、暂时失效、不支持链接、取消和网络中断有真实状态和脱敏诊断。
- [ ] 项目素材可预览并被下游引用，外部 URL 不成为运行依赖。
- [ ] UI 显示独立适配器身份、固定版本和最近真实验证时间。

## Verification evidence

- E1 固定实现、提交、许可证和适配范围记录。
- E2 覆盖 URL、短链、会话、错误分类、取消、幂等和回滚。
- E3 使用一份授权快手金标 URL 完成真实导入、哈希、来源登记和预览。

## Out of scope

- 用未固定的通用 URL 抓取证明平台支持。
- 绕过平台风控、访问控制或发布回快手。
