# 29: 关闭 CanvasEngine C01–C35 参考验收

**What to build:** 在固定视口、节点数据和操作状态下，对照 Toonflow 主体与已核查补充参考，逐项验证 C01–C35 的页面结构、直接操作、节点能力、持久化、异常、取消、恢复、真实生成、可访问性和跨引擎使用，修复本范围内差异并形成可审计结论。

**Blocked by:** 09: 收口可选 ComfyUI 适配器与能力声明; 25: 完成画布直接操作、剪贴板与撤销重做; 26: 完成画布文本、媒体、引用与处理节点; 27: 从画布执行文本图片视频生成; 28: 从画布委托混剪并交付受控 AgentAction

**Status:** ready-for-agent

## Scope

- 逐项关闭 C01–C35；未核查的综合参考能力保持失败或阻塞，不能默认排除。
- 主体 UI 只以 Toonflow 固定提交为准，其他参考只补充其缺少的媒体、引用、插件、剪贴板和续创能力。
- 验证桌面与窄屏关键操作、可访问名称、焦点、键盘路径、持久化和冲突恢复。
- 对每个允许差异记录项目数据、API 或平台限制理由，未批准主体差异必须为零。

## Source reuse prerequisite

- 汇总前序票据的 Toonflow、basketikun/infinite-canvas、XYFlow 及其他参考源码/许可记录。
- 对 C35 中每个新增参考能力先读实际源码再决定复制、适配、自研或明确不适用。

## Acceptance criteria

- [ ] C01–C35 每项均有合法状态和规定证据，不存在空白或仅凭截图通过。
- [ ] 页面区域、节点层级、工具位置、打开/关闭、拖拽连线、选择、多选、菜单和编辑器无未批准主体差异。
- [ ] 正常、异常、取消、恢复、并发冲突和真实服务路径均可重复执行。
- [ ] 桌面和窄屏关键操作、焦点、键盘路径和 WCAG 2.1 AA 相关要求有证据。
- [ ] 画布结果可进入项目素材、制作镜头或商业混剪，且节点不强制归属 Shot。
- [ ] 所有复制/改造组件具有固定来源、提交、许可证、落点、适配与测试记录。

## Verification evidence

- E1 完整源码与许可证映射；E2 领域/API/UI 自动化；E3 真实生成与项目素材；E4 参考操作录像和人工视觉/可用性检查。
- 对 C01–C35 生成逐项差异表，失败和阻塞继续留在分母。
- 复用已有有效结果，仅在相关状态变化或新疑点时重跑。

## Out of scope

- 用局部操作、空画布或视觉相似度宣称完整对齐。
- 多人实时协作、自主 Agent 循环和全站视觉改造。
