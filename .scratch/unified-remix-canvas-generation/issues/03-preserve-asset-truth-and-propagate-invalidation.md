# 03: 统一项目素材结果安装与版本失效传播

**What to build:** 让任一受控运行产生的图片、视频或音频结果都通过现有项目素材系统安装为不可变版本，并让文本结果在明确采用前保持不可变运行输出。以一次真实本地媒体产物为 tracer bullet，贯通结果安装、稳定引用、界面预览、下游引用和预览/批准失效。

**Blocked by:** 02: 扩展共享运行契约并兼容迁移旧记录

**Status:** resolved

## Scope

- 复用现有项目素材身份、版本、预览和来源记录，不建立生成专用素材库。
- 定义媒体结果安装、文本结果采用、当前选中输出和历史输出的稳定关系。
- 将来源素材、脚本、生成结果、当前输出、`RemixPlan`、编辑序列、裁剪、包装、字幕、音频、模型和配置变化映射到现有预览与批准失效规则。
- 兼容旧素材和既有文本/图片结果，不重新生成或改写其稳定身份。

## Source reuse prerequisite

- 先阅读项目素材安装、编辑序列快照、预览审核、交付门禁和现有结果回填源码。
- 优先复用现有版本比较和审核失效实现；仅为缺失的跨引擎来源关系做必要扩展。

## Acceptance criteria

- [x] 一个真实本地媒体运行结果安装后获得稳定项目素材身份、内容哈希、来源运行和不可变版本。
- [x] 同一结果重复安装幂等，文件重名不会替换已引用素材。
- [x] 文本结果在生成完成后不自动改写画布、脚本或计划，明确采用后才形成领域内容版本。
- [x] 切换当前输出或修改影响成片的输入会使所有依赖预览和批准明确失效，历史记录仍可查看。
- [x] 旧素材、旧文本和旧图片结果兼容读取，不因统一来源关系而重新生成或丢失来源。
- [x] 界面能从结果追溯到运行、Provider/处理方式、输入快照和下游引用。

## Verification evidence

- 合同测试覆盖安装幂等、重名、旧数据、文本采用、输出切换和失效传播。
- 使用真实媒体文件验证项目素材预览及编辑序列引用，不以临时路径旁路。
- 审核门禁测试证明失效后的旧批准不能导出新版本。

## Out of scope

- 实现具体文本、图片或视频 Provider。
- 改写现有 Timeline、审核或交付系统。

## Comments

### 2026-10-01 实施与证据

- 媒体结果继续以 `ProjectAssets` 和 `PreproductionStore` 为唯一项目素材真相源：`install_run_result` 为图片、视频、音频结果生成稳定 `assetId` 与唯一 `assetVersionId`，保存 SHA-256、运行/结果来源、可选公共运行、Provider/处理方式和冻结输入快照/指纹；同一运行结果重复安装返回原记录，内容、输入或已安装文件发生变化时拒绝覆盖。展示名称与内部文件名分离，同名结果不会替换已有引用。
- 文本结果使用独立 `result_truth` 合同：生成完成只返回不可变运行输出，不修改画布、脚本或计划；只有显式采用命令才形成带来源运行/结果的领域版本。确定性版本 ID 由规范化身份元组派生，重复采用幂等，并兼容旧 `results[]` / `result` 读取形状。
- 预览、审核和交付继续复用 `batch_production` 既有状态机，只新增受控 `productionDependencies` 快照与指纹。来源素材、生成结果、当前输出、RemixPlan、编辑序列、裁剪、包装、字幕、音频、模型和配置任一变化都会使旧预览与旧批准 stale；历史运行和审核记录保留，旧批准不能导出新版本。旧任务和旧预览双方都没有新指纹时保持兼容；只有一方缺失时明确失效。
- `AssetManager` 复用现有素材详情和引用端点，以局部兼容投影展示运行/结果、Provider/处理方式、`assetVersionId`、内容哈希、输入指纹、冻结输入快照和既有下游引用；旧 `versionId` 仅作为只读兼容显示，不修改共享 API 类型或旧记录。
- 真实 tracer 使用本机 FFmpeg 生成两份内容不同的 MP4，经统一结果安装进入项目素材；首轮使用结果 1，切换到结果 2 时经正式 dependencies API 同步更新实际编辑轨道，再由真实编辑序列生成预览与交付，并用 ffprobe 校验输出。旧预览/审核历史仍存在且导出返回 409，新预览、批准与交付只引用结果 2；没有通过临时路径或直写 batch state 绕过项目素材。
- 源码复用/适配：实现前核对并直接复用项目内 `project_assets.py`、`render_inputs.py`、`timeline.py`、`batch_production.py`、`batch_editing_api.py`、`asset_references.py`、`preproduction_api.py` 与 `AssetManager.tsx` 的素材安装、私有输入、编辑序列、审核/交付门禁和引用展示。没有复制第三方源码，也没有新增许可证或生成专用素材库；新增代码仅为缺失的结果安装、文本采用和跨引擎依赖适配。
