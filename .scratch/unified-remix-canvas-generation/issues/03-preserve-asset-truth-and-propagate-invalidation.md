# 03: 统一项目素材结果安装与版本失效传播

**What to build:** 让任一受控运行产生的图片、视频或音频结果都通过现有项目素材系统安装为不可变版本，并让文本结果在明确采用前保持不可变运行输出。以一次真实本地媒体产物为 tracer bullet，贯通结果安装、稳定引用、界面预览、下游引用和预览/批准失效。

**Blocked by:** 02: 扩展共享运行契约并兼容迁移旧记录

**Status:** ready-for-agent

## Scope

- 复用现有项目素材身份、版本、预览和来源记录，不建立生成专用素材库。
- 定义媒体结果安装、文本结果采用、当前选中输出和历史输出的稳定关系。
- 将来源素材、脚本、生成结果、当前输出、`RemixPlan`、编辑序列、裁剪、包装、字幕、音频、模型和配置变化映射到现有预览与批准失效规则。
- 兼容旧素材和既有文本/图片结果，不重新生成或改写其稳定身份。

## Source reuse prerequisite

- 先阅读项目素材安装、编辑序列快照、预览审核、交付门禁和现有结果回填源码。
- 优先复用现有版本比较和审核失效实现；仅为缺失的跨引擎来源关系做必要扩展。

## Acceptance criteria

- [ ] 一个真实本地媒体运行结果安装后获得稳定项目素材身份、内容哈希、来源运行和不可变版本。
- [ ] 同一结果重复安装幂等，文件重名不会替换已引用素材。
- [ ] 文本结果在生成完成后不自动改写画布、脚本或计划，明确采用后才形成领域内容版本。
- [ ] 切换当前输出或修改影响成片的输入会使所有依赖预览和批准明确失效，历史记录仍可查看。
- [ ] 旧素材、旧文本和旧图片结果兼容读取，不因统一来源关系而重新生成或丢失来源。
- [ ] 界面能从结果追溯到运行、Provider/处理方式、输入快照和下游引用。

## Verification evidence

- 合同测试覆盖安装幂等、重名、旧数据、文本采用、输出切换和失效传播。
- 使用真实媒体文件验证项目素材预览及编辑序列引用，不以临时路径旁路。
- 审核门禁测试证明失效后的旧批准不能导出新版本。

## Out of scope

- 实现具体文本、图片或视频 Provider。
- 改写现有 Timeline、审核或交付系统。
