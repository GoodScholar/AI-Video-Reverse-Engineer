# 20: 统一脚本驱动商业混剪为 RemixPlan

**What to build:** 把已确认脚本、多份项目素材、片段索引、视觉召回和候选复排收口到 `RemixEngine` 脚本入口，生成与高光入口相同的 `RemixPlan`，并在不覆盖人工编辑的前提下采用为现有变体编辑序列。

**Blocked by:** 01: 冻结五张验收矩阵与三条金标接缝; 03: 统一项目素材结果安装与版本失效传播

**Status:** ready-for-agent

## Scope

- 复用现有片段索引、本地视觉召回、显式披露后的云端复排、混剪规划和批量变体能力。
- 计划包含脚本段落、来源区间、顺序、时长、词边界、节拍建议、重复抑制、跨变体差异和选择理由。
- 提案生成、保存、替换、禁用和采用都使用修订校验；人工编辑存在时显式覆盖、合并或放弃。
- 采用后沿用现有 Timeline、配音字幕、预览、审核和交付链。

## Source reuse prerequisite

- 先阅读现有素材索引、视觉检索、混剪规划、批量编辑和编辑序列源码，确认哪些行为已经通过验证。
- MoneyPrinterTurbo、NarratoAI、ShortGPT 等只在读取固定源码、许可和实际模块后选择性复用；不得引入其项目、任务或存储系统。

## Acceptance criteria

- [ ] 已确认脚本与多素材生成一份版本化、可解释的 `RemixPlan`。
- [ ] 每段计划保存候选、来源区间、分数/理由、时长和选择规则，用户可替换或禁用。
- [ ] 词边界和脚本语义优先于节拍，重复素材与相似构图受控，结果确定可复现。
- [ ] 多个变体共享素材但镜头安排具有可测差异，不是相同序列复制。
- [ ] 重新生成提案不覆盖人工编辑；采用时显式处理修订冲突。
- [ ] 采用结果是现有编辑序列，可继续配音、字幕、预览、审核和交付。

## Verification evidence

- 固定候选集测试覆盖脚本覆盖、持续时间、无重叠、少重复、差异、词边界、节拍、理由和确定性。
- UI 测试覆盖披露、候选来源、替换、禁用、冲突和采用。
- 使用真实项目素材形成可播放初稿，质量关账由票据 22 和 31 完成。

## Out of scope

- 自动生成缺失素材；由票据 21 完成。
- 引入第二套 Timeline、渲染、审核或交付链。
