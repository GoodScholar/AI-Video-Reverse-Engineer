# 28: 从画布委托混剪并交付受控 AgentAction

**What to build:** 增加画布混剪节点和首期受控 `AgentAction`：混剪节点只委托 `RemixEngine` 并以项目素材结果回到画布；Agent 使用与人工相同的领域命令先生成可查看、可审计的变更提案，经用户确认后应用并可撤销。

**Blocked by:** 20: 统一脚本驱动商业混剪为 RemixPlan; 24: 分离画布业务节点与视图并建立执行 DAG; 27: 从画布执行文本图片视频生成

**Status:** ready-for-agent

## Scope

- 混剪节点接收稳定素材、脚本或文本结果引用，委托 `RemixEngine`，保存 `RemixRun` 与计划引用而不复制结果。
- `AgentAction` 只组合受控画布领域命令，提案展示新增、修改、删除和连接差异。
- 用户确认后原子应用；拒绝不改变画布；应用后可撤销且留下审计记录。
- Agent 不直接改数据库、不越权调用 Provider、不自动批准预览或交付。

## Source reuse prerequisite

- 阅读 Toonflow 固定提交的 Agent 操作画布、项目/资产组织与变更应用源码。
- 阅读现有画布命令、撤销重做和 `RemixEngine` 提案/采用接口；只复用许可清晰且适合受控提案的部分。

## Acceptance criteria

- [ ] 画布混剪节点通过 `RemixEngine` 生成计划/运行引用，结果以项目素材身份返回。
- [ ] 混剪结果可继续连接下游节点且不强制归属制作镜头。
- [ ] Agent 提案显示具体节点、连接、参数和引用变化，确认前不修改画布。
- [ ] 接受提案使用与人工相同的领域命令、版本校验和权限，拒绝保持原状态。
- [ ] 已应用提案可撤销，审计记录包含提案、确认者、修订和结果。
- [ ] Agent 不能直接调用未授权 Provider、修改数据库或批准交付。

## Verification evidence

- 领域/API/UI 测试覆盖混剪委托、素材返回、提案预览、确认、拒绝、冲突和撤销。
- 使用真实项目素材完成一次画布到混剪再回画布的可播放路径。
- 安全测试证明越权命令、未确认 Provider 和自动批准被拒绝。

## Out of scope

- 自主长期 Agent 循环和无人监督生产。
- 多人实时协作或 Agent 直接发布。
