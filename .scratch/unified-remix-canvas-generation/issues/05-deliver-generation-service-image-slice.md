# 05: 交付统一图片生成纵向切片

**What to build:** 在统一生成门面上接入一个图片适配器，让用户按真实能力完成文生图、单图或多图参考、可选图片编辑和多结果生成；每个成功结果都安装为项目素材，失败结果和历史运行保持可见，并可被下游画布或混剪引用。

**Blocked by:** 04: 交付统一文本生成纵向切片

**Status:** ready-for-agent

## Scope

- 为图片模态增加输入数量、参考类型、编辑、比例、分辨率和结果数量能力描述及服务端校验。
- 支持逐结果成功/失败、部分成功、取消、超时、重试和幂等。
- 复用已验证的图片服务与项目素材安装链，不重写模型调用或另建生成图库。
- 在界面上区分模型图片编辑、普通本地裁切/缩放和模型超分辨率。

## Source reuse prerequisite

- 先阅读现有图片生成、图片处理、素材入库和结果预览源码，并核对现有 Provider 的官方能力与真实探针。
- 记录适配器版本、直接复用范围和必要字段映射；未知或未验证能力不得推断为支持。

## Acceptance criteria

- [ ] 文生图、单图参考和多图参考仅按适配器真实能力显示、校验和提交。
- [ ] 图片编辑只在真实支持时开放，普通裁切/缩放不显示为模型编辑或超分。
- [ ] 比例、分辨率、输入数量和结果数量在客户端提示并由服务端权威校验。
- [ ] 多结果逐项保存成功/失败；取消或单项失败不删除已成功结果。
- [ ] 成功结果以不可变项目素材版本入库，可预览、下载并被下游稳定引用。
- [ ] 重试创建新运行且遵守幂等，不覆盖旧结果或重复安装素材。

## Verification evidence

- 协议假服务覆盖多输入、多结果、部分失败、取消、超时和能力拒绝。
- 使用真实图片文件验证素材入库、预览、下载和下游引用。
- 真正 Provider 的通过证据由票据 08 完成，本票只证明合同和本地数据链。

## Out of scope

- 视频生成和 ComfyUI Workflow。
- 自研图片模型或普通处理算法重写。
