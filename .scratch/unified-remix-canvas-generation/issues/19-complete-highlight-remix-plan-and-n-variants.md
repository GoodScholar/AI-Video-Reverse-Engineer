# 19: 完成长视频高光到 RemixPlan 与 N 条变体

**What to build:** 把转录、高光候选和竖屏重构接入 `RemixEngine` 高光入口，生成唯一版本化 `RemixPlan`，按 Top N 物化到现有短视频变体编辑序列，并贯通预览、部分成功、检查点重试、审核和批准导出。

**Blocked by:** 03: 统一项目素材结果安装与版本失效传播; 17: 交付高光候选、去重与 Top N 纵向切片; 18: 交付主体感知 9:16 重构纵向切片

**Status:** ready-for-agent

## Scope

- 高光入口只生成 `RemixPlan`，不创建第二套短视频计划或时间线。
- `RemixPlan` 保存候选身份、来源区间、顺序、裁剪轨迹、包装引用和版本；采用后写入现有编辑序列。
- 运行保存请求 N、候选数、成功数、失败数和每条结果身份；单条失败保留成功结果。
- 使用现有 Timeline/FFmpeg、预览、审核和批准导出链。

## Source reuse prerequisite

- 阅读现有短视频变体、编辑序列、预览、审核、导出和批量状态源码。
- 对照 Anil 固定提交的 pipeline 与 clipper，只复用已核查的本地行为，不引入 MuAPI 任务或输出命名方式。

## Acceptance criteria

- [ ] 高光入口生成的候选计划使用与脚本入口相同的版本化 `RemixPlan` 协议。
- [ ] 用户可查看、保存、选择和采用计划；采用结果写入现有编辑序列并保留来源。
- [ ] 请求 N 条时保存请求、候选、成功、失败数量和每条稳定身份。
- [ ] 只有 N 条均成功为完整成功；部分成功保留可预览和可审核结果。
- [ ] 单条失败、取消、输出重名、进程重启和重试不删除成功结果或重复采用。
- [ ] 每条变体完成真实预览、人工审核门禁和批准导出，影响输入变化使旧批准失效。

## Verification evidence

- 领域/API/UI 测试覆盖计划版本、采用、部分成功、幂等、重启和审核失效。
- E3 一份授权真实视频完成 Top N、竖屏媒体、编辑序列、预览和项目素材入库。
- E4 人工检查音画、来源、构图和批准导出关系。

## Out of scope

- 六份金标总体质量关账；由票据 30 完成。
- 独立渲染器、审核或交付系统。
