# 27: 从画布执行文本图片视频生成

**What to build:** 让画布节点通过 `GenerationService` 选择真实 Provider/模型能力，冻结依赖子图与输入顺序，批量执行文本、图片和视频生成，管理多结果、当前输出、取消、失败、重试、恢复和下游过期，并把媒体结果入库后继续创作。

**Blocked by:** 08: 验证文本图片视频真实 Provider 闭环; 24: 分离画布业务节点与视图并建立执行 DAG; 26: 完成画布文本、媒体、引用与处理节点

**Status:** ready-for-agent

## Scope

- 节点只消费统一能力目录，不直接编排具体 Provider 或暴露任意 Provider JSON。
- `CanvasExecution` 冻结画布修订、依赖子图、输入顺序、配置和能力快照，并引用 `GenerationRun`。
- 多结果逐项可预览、下载、复制、重试或删除；节点只保存当前选中输出稳定引用。
- 上游变化或切换输出使下游过期，不自动重复运行或计费。

## Source reuse prerequisite

- 阅读 Toonflow 固定提交的图像/视频节点、模型选择、结果展示和执行交互源码。
- 阅读 basketikun/infinite-canvas 的生成记录、多引用和续创源码；仅通过现有 `GenerationService` 接入。

## Acceptance criteria

- [ ] 文本、图片和视频节点只显示真实能力支持的模型、输入、比例、分辨率、时长、首尾帧和音频组合。
- [ ] 执行冻结有序输入与能力快照，刷新/重启后显示相同运行和结果。
- [ ] 批量依赖执行遵守 DAG 顺序；上游失败、取消或未知时下游显示阻塞而非误跑。
- [ ] 本地停止、远端取消、取消不支持、迟到结果和费用未知在节点中真实可见。
- [ ] 多结果保持不可变历史，切换当前输出使下游过期但不自动提交。
- [ ] 成功媒体入库为项目素材并可用于下游生成或混剪，文本需明确采用。

## Verification evidence

- 合同测试覆盖能力校验、顺序、阻塞、取消、未知、重试、幂等、多结果和过期传播。
- E3 真实文本、图片和视频 Provider 分别从画布执行并产生可用结果。
- E4 人工检查画布操作、媒体预览和下游续创关系。

## Out of scope

- 直接从画布绕过统一门面调用 Provider。
- 自动重跑过期节点或自主长期循环。
