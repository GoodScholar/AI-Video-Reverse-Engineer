# 18: 交付主体感知 9:16 重构纵向切片

**What to build:** 对一个已选择的项目视频区间生成版本化竖屏裁剪轨迹，支持人物、人脸、商品和其他主体、跨帧身份保持、场景切换后重选、置信度与人工关键帧覆盖，并通过现有 FFmpeg 形成无黑边、音画同步的 9:16 项目素材。

**Blocked by:** 16: 交付 faster-whisper 长视频绝对时码转录

**Status:** ready-for-agent

## Scope

- 裁剪轨迹以源时间坐标保存主体框、选择身份、置信度、场景边界、算法版本和人工覆盖。
- 正式输出必须裁满 9:16；无法在安全区保留主体时标记待处理，不使用黑色 letterbox 冒充完成。
- Haar 最大脸 + EMA 仅作为明确记录的最低回退，不作为默认商用终点。
- 贯通轨迹预览、人工修正、渲染、媒体探测、素材入库和下游引用。

## Source reuse prerequisite

- 阅读 Anil 固定提交中的 OpenCV/Haar/EMA 裁切源码，记录可复用部分和身份、商品、场景切换等缺口。
- 阅读项目现有主体跟踪、裁剪、Timeline/FFmpeg 和安全区源码；优先复用成熟跟踪和渲染能力。

## Acceptance criteria

- [ ] 单人、人脸短暂消失、多人交替、商品/非脸主体、快速运动和场景切换有可观察轨迹。
- [ ] 跨帧保持同一主体，场景切换后按规则重选；错误选择可用人工关键帧覆盖。
- [ ] 轨迹、主体框、置信度、算法版本和人工覆盖随结果保存并可追溯。
- [ ] 最终 9:16 媒体无黑边、无越界、音画同步，主体与字幕安全区可人工检查。
- [ ] 无法安全构图时阻止正式完成并标记待处理，不静默裁掉主体。
- [ ] 轨迹或人工覆盖变化使依赖预览和批准失效，历史输出保留。

## Verification evidence

- E2 使用合成移动主体、交叉、切场和非脸目标媒体验证轨迹、边界与无黑边。
- E3 使用授权真实视频完成轨迹、人工覆盖、FFmpeg 渲染和项目素材入库。
- E4 逐帧/关键帧人工检查主体身份、安全区、无黑边和音画同步。

## Out of scope

- 训练新的检测或跟踪模型。
- 用一次最大脸检测证明人物、商品和身份保持全部通过。
