# 14: 真实导入小红书视频为项目素材

**What to build:** 通过固定版本、许可已核查且真实验证的来源适配器，把用户有权使用的小红书公开页面、正常分享链接或合法会话可访问视频导入现有项目素材，保存准确来源、状态、诊断和预览。

**Blocked by:** 10: 建立统一视频来源合同并贯通本地导入

**Status:** ready-for-agent

## Scope

- 识别标准页面、正常分享文本和短链，安全解析重定向并探测媒体。
- 权利确认后下载、校验、哈希、来源登记和入库；会话只由系统安全存储管理。
- 保存适配器版本、最近真实验证时间、原始/最终来源与四态状态。

## Source reuse prerequisite

- 阅读所选 yt-dlp 固定版本的小红书 extractor、重定向、Cookie、签名/接口与错误分类源码。
- 若所选版本不支持目标链接，核对许可后选择替代实现并记录原因，不能以通用 URL 偶然成功替代正式适配器。

## Acceptance criteria

- [ ] 正常页面、分享链接和短链正确识别，危险或非目标重定向被拒绝。
- [ ] 权利确认、合法会话和禁止自动登录/绕过访问控制规则生效。
- [ ] 会话失效、风控、链接失效、取消和网络中断有真实状态与脱敏诊断。
- [ ] 真实媒体完成探测、哈希、来源登记、入库和预览。
- [ ] 下游只引用项目素材身份，刷新或外部链接变化不破坏已入库内容。
- [ ] UI 显示适配器版本和最近真实验证时间。

## Verification evidence

- E2 覆盖 URL/短链、重定向、登录要求、错误分类、取消和脱敏。
- E3 使用一份授权小红书金标 URL 完成真实导入、哈希、来源登记和预览。
- 人工核对真实媒体和来源元数据一致。

## Out of scope

- 绕过平台访问控制或批量采集账号内容。
- 自动发布或互动功能。
