# 25: 完成画布直接操作、剪贴板与撤销重做

**What to build:** 在 Toonflow 主体画布上完成添加、搜索、上传、拖放、粘贴、选择、平移、缩放、框选、多选、聚焦、右键菜单、复制副本、删除、分组、嵌套、解组、改名、工具栏偏好和撤销重做，并保证每次操作同时维护业务身份、连接与持久化结果。

**Blocked by:** 24: 分离画布业务节点与视图并建立执行 DAG

**Status:** ready-for-agent

## Scope

- 直接操作遵循 Toonflow 固定版本的入口、工具位置、打开/关闭和编辑器交互。
- 复制/粘贴节点或子图生成新身份，保留内部关系；跨项目素材引用必须校验或明确拒绝。
- 分组、嵌套和布局整理不改变业务内容和执行连接。
- 撤销重做覆盖位置、连线、参数、引用、输出选择和图片替换。

## Source reuse prerequisite

- 阅读 Toonflow 固定提交的选择、菜单、浮动工具、剪贴板、分组和撤销重做源码。
- 阅读 basketikun/infinite-canvas 固定提交 `dab19adc0847e32e39b7fc8ff90cb392561fb826` 的剪贴板、节点序列化和迁移源码，核对 MIT 许可与适配点。

## Acceptance criteria

- [ ] 添加菜单、搜索、上传、拖放和粘贴都产生有效、可保存的节点或素材。
- [ ] 鼠标、键盘和触摸完成选择、平移、缩放、框选、多选与聚焦，焦点状态可见。
- [ ] 右键复制、副本、删除和剪贴板按来源语义保留或排除连线。
- [ ] 粘贴子图生成新身份并保留内部关系，跨项目素材不会形成悬空引用。
- [ ] 分组、嵌套、解组和布局整理后节点内容与执行连接不变。
- [ ] 撤销重做覆盖规定操作，刷新后已保存结果与历史一致。
- [ ] 工具栏动作/标签偏好可持久化，隐藏动作仍能从菜单访问。

- UI/领域测试覆盖身份、连接、剪贴板、跨项目拒绝、分组和撤销栈。
- 手工键盘路径与触摸行为检查。
