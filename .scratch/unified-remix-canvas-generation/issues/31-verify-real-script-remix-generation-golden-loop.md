# 31: 验收脚本混剪与缺失生成真实金标闭环

**What to build:** 使用已确认脚本和多份授权项目素材完成第二条最高测试接缝：生成可解释 `RemixPlan`，由用户确认后通过真实 `GenerationService` 补齐缺失文本/图片/视频，重新解析计划，形成差异化多变体并完成预览、质检、人工审核和批准交付。

**Blocked by:** 21: 生成并重新解析 RemixPlan 缺失素材; 22: 完成商业混剪包装、质检与质量门槛

**Status:** ready-for-agent

## Scope

- 真实项目包含已确认脚本、多份视频/图片/音频素材和至少一项缺失生成需求。
- 缺失生成前展示 Provider、模型、外发内容、费用和取消语义；结果入库后重新解析新计划版本。
- 形成多个镜头安排不同的变体，完整经过配音字幕、包装、预览、质检、审核和导出。
- 记录镜头保留率、人工替换率、黑边、安全区和预览/导出一致性。

## Source reuse prerequisite

- 汇总脚本混剪、生成适配器、Timeline/FFmpeg、字幕包装、质检和审核交付的源码与许可证据。
- 不通过临时脚本、临时文件或独立时间线绕过统一边界。

## Acceptance criteria

- [ ] 已确认脚本和多素材生成带候选、来源、理由和版本的 `RemixPlan`。
- [ ] 缺失文本/图片/视频在用户确认后由真实 Provider 生成并以项目素材身份入库。
- [ ] 重新解析产生新计划修订，旧计划和旧结果保留，人工编辑不被静默覆盖。
- [ ] 多个变体具有可测镜头差异并完成包装、预览、质检、人工审核和批准导出。
- [ ] 镜头保留率至少 80%、人工替换率不超过 20%，9:16 无黑边且主体/字幕安全区通过。
- [ ] 失败、取消、状态未知、迟到结果、输入修订和重启恢复至少各有适用证据。
- [ ] X07–X10、X16–X18 与相关 R/G/A 项获得 E3/E4 证据。

## Verification evidence

- 真实 Provider 运行、项目素材、计划版本、编辑序列、预览、质检、审核和交付产物。
- 人工记录镜头保留、替换、包装质量、内容审核和失败恢复。
- API 单独成功或模拟 Provider 不能作为本票通过证据。

## Out of scope

- 自动批准、自动发布或未确认费用的生成。
- 建立生成专用项目、素材或交付系统。
