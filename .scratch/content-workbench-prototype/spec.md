## 原型位置

- 组件：`frontend/src/ContentStudioPrototype.tsx`
- 样式：`frontend/src/contentStudioPrototype.css`
- 已授权演示媒体：`frontend/src/contentPrototypeMedia/`
- 现有根页面开发参数：`?prototype=content-studio&variant=A|B|C`
- 启动：在 `frontend` 执行 `npm run dev -- --host 127.0.0.1 --port 5188 --strictPort`
- 访问：`http://127.0.0.1:5188/?prototype=content-studio&variant=A`

入口受 Vite DEV 开关控制，生产构建不会输出原型组件、样式与媒体。普通工作台的 App 代码与接口保持原有执行路径。数据仅在内存；刷新重置，不提交任何项目修改或模型请求。

## 三种布局

- A：步骤式制作，当前步骤为主要编辑区域，右侧样片与制作检查。适合内部人员顺序完成一次制作。
- B：素材、预览及时间线、当前步骤三栏。适合精修一条内容。
- C：批量内容表与当前处理面板。适合集中查看每条脚本、声音方案和审核状态。

底部按钮、选择框或非输入区域的左右方向键可切换布局；切换保留当前内存内容。输入框方向键用于正常编辑。

## 范围与限制

覆盖商品简报、发送内容披露、5 条脚本编辑与逐条确认、音色选择、本机实测与自定义试听文件播放/停止、编排、失败状态和审核门槛。只有已通过的审片示意才能下载原型记录 JSON。

脚本生成、配音混剪、选材理由和审核都是明确标示的模拟状态。音色卡片现展示本机已实测的九种预置音色，附声音特点、语言/口音、适用场景与固定同文案音频。样音直接复用本轮已生成的 WAV，没有额外下载；当前脚本的实际配音与正式服务接口待接入。载入自定义音频时标明需要自行核对声音是否对应。所用视频是前期公开素材演示样片，没有按本次编辑重新合成。

媒体沿用 `.scratch/batch-short-video-editing/public-demo-acceptance.md` 已记录的 Pexels 来源与许可；未使用用户已拒绝的本机 TTS 音色。正式服务仍需满足 `.scratch/aigc-ecommerce-content/issues/05-pre-mix-voice-selection.md`。
