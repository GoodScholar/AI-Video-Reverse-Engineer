# 商品图片检索与导入实施计划

Goal: 商品名称即可开始制作准备；已有素材优先，无素材时搜索并核对导入真实商品图片。
Architecture: 复用前置素材库存储和正式制作入口，新增项目级图片检索/预览/导入接口；AnySearch匿名搜索公开网页，来源页面提取图片候选，下载仅访问公网HTTP(S)。导入后同步素材页、制作预览和精修，保持草稿。
Tech Stack: 现有FastAPI、Python标准库、Pillow、React，无新依赖。
Spec: [试点规格](spec.md)

## 约束

- 只发送商品名称查询，不发送原始媒体、凭据或完整商品资料。
- 不调用收费脚本、图像或视频生成服务进行验收，不自动提交。
- 候选可预览、核对来源后导入；不把网页图片标记为已获得商业授权，不混用包装规格。
- 图片下载验证DNS、重定向、大小及真实格式，拒绝本地/私网、凭据URL及非HTTP(S)。
- 搜索空结果或图片失败可重试，不伪造素材成功；同项目导入按来源去重。
