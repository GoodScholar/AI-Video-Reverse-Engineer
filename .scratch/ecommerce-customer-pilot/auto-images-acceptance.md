# 商品名称与网络图片流程验收

日期：2026-09-26。范围：正式工作台功能；不代表客户成片验收通过。

## 实现

- 商品名称必填，其他创作资料折叠为选填。已有可用素材优先补足两份，不要求填写事实或上传图片才能开始准备。
- 缺少素材时，匿名检索商品名称，读取公开来源，展示图片、来源链接及核对导入。来源均衡展示，避免单站的失效 CDN 占满候选。
- 下载只允许公网 HTTP(S)，校验 DNS 并固定连接地址，逐跳检查重定向；本机代理合成 DNS 使用受验证的公共 DNS 结果。限制页面/图片大小、真实格式和尺寸；图标、常见二维码排除，无法预览的候选禁选。
- 图片加入原素材库，来源与下载时间随素材保留；重复导入去重，原文件缺失时修复文件并保留素材 ID 和客户编辑。
- 全站预览、素材与精修共用新素材，保留镜头草稿；低版本回包不能覆盖新导入状态。前置节点与导入使用同一可重入写入锁。
- 未填写事实时只补商品名称及不推断价格、功效、市场表现的限制；不将网络摘要自动变成商品事实。
