# 02: 生成五条脚本并确认交接

Status: ready-for-agent
Type: task
Blocked by: 01

## What to build

交付人员在正式制作界面核对发送内容，生成五条有事实依据且对应当前素材的候选，逐条保存确认后交给批量混剪。

依据：[真实商品试点规格](../spec.md)。

## Acceptance criteria

- [ ] 核对允许的服务、模型、当次发送文字和费用条件；取消一次披露不生成，确认后才发送
- [ ] 五条候选逐条检查事实、禁用表达、素材引用和镜头顺序，差异体现在卖点或叙事安排
- [ ] 修改候选后保存并确认当前简报及候选版本；五条确认后真实交接
- [ ] 记录项目、生成批次、候选和交接任务标识及审核理由；失败重试遵循费用条件
