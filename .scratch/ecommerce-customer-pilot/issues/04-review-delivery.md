# 04: 审核导出并记录试点结论

Status: ready-for-human
Type: task
Blocked by: 03

## What to build

指定审核人员核对至少两条真实预览并给出结论，通过项导出后能在普通播放器播放，交付文件与批准版本一致，形成可追溯验收记录。

依据：[真实商品试点规格](../spec.md)。

## Acceptance criteria

- [ ] 至少两条成片获得具体通过或退回理由，检查事实、授权、镜头、读音、音量及字幕可读性
- [ ] 只导出当前有效通过作品；与批准的内容、变体、字幕和预览版本对应
- [ ] 下载MP4检查720×1280、30fps、音视频流、实际时长和完整可播放性，记录文件SHA-256
- [ ] 使用剩余未交付变体核验内容修改后旧预览/审核失效，不改写已批准交付文件
- [ ] 记录通过、退回及未完成项；真实缺陷用复现和受影响回归修复后重新审核

## Comments

Agent可以完成技术检查，但客户内容通过结论必须来自指定审核人员。未获意见时保留待人工审核，不默认批准。
