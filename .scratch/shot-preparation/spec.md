# 独立逐镜头素材准备

用户确认方向：参考 VACE 的前处理与生成分离、完整镜头时间线、按需控制素材、素材审查和独立准备包。无需 ComfyUI；不自动调用付费服务，不启动用户后端。

本次实施：复用已持久化镜头切点，覆盖完整视频，逐镜头代表帧、备注与四语言正负提示词编辑、显式逐镜头分析、控制素材状态、独立 ZIP。复用现有深度产物，不将深度标成姿态或遮罩。姿态/遮罩模型适配尚未实现，必须如实显示，后续不能宣称完整动作捕捉完成。

验证：多镜头首尾连续覆盖，逐镜头帧仅取对应时间范围，草稿版本冲突与来源替换，导出不要求 ComfyUI 或整片单镜头门禁；独立 provider 假对象验证不发送完整视频；前端异步错误、只读、保存与导出。
