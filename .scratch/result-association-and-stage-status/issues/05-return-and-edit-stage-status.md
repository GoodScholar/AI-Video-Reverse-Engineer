# 05: 显示结果回传与剪辑阶段状态

**What to build:** 创作者在流程中看到候选回传、人工复核和本地剪辑的实际状态，并知道下一步在哪里处理。

**Blocked by:** 04 显示准备阶段的缺项与位置。

**Status:** resolved

- [x] 回传阶段区分候选存在、时长满足要求、方案关联已变化和人工复核；上传文件本身不等于已验收。
- [x] 剪辑阶段依据已保存时间线及现有导出检查显示进展，警告不被当作阻断错误。
- [x] 外部生成阶段始终描述为应用外完成的工作，不显示为应用已验证。
- [x] 未保存的工作台或时间线草稿不会计入已保存进度，并给出明确提示。
- [x] 通过现有候选、时间线 API 和流程界面验证状态与导航。
