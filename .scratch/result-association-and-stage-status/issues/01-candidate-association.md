# 01: 保存候选的原始方案关联

**What to build:** 创作者关联镜头结果时，候选详情保存并显示当时已保存的方案摘要和候选专属外部制作备注；后续修改、复核和采用均不改写原始关联。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 上传结果或首次选择已有视频为候选时，服务端保存镜头需求、提示词、计划时长、素材和步骤的关联摘要；新关联在界面可读。
- [x] 修改方案后仍可查看原始摘要，同时沿用现有“方案已变化”和人工复核规则。
- [x] 候选可单独记录、修改可选的外部制作备注；界面明确说明关联与备注均不证明外部模型的实际运行过程。
- [x] 旧候选没有原始摘要时显示“历史关联内容不可还原”，不拿当前方案冒充历史方案；原有候选采用和移除行为保持可用。
- [x] 通过现有前置工作台 HTTP API 与可见候选界面验证上述行为。
