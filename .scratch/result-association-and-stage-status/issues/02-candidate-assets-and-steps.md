# 02: 定位候选关联的素材与步骤

**What to build:** 创作者从候选的原始方案关联查看其素材和步骤，并进入仍存在的项目位置；历史信息即使已失效也能辨认。

**Blocked by:** 01 保存候选的原始方案关联。

**Status:** resolved

- [x] 候选详情显示关联时的素材标识与可读名称、步骤类型、输入和关键参数，不依赖当前方案重新拼接历史。
- [x] 仍存在的素材与步骤可进入相应位置；已删除或不可服务的素材仅保留历史说明，不提供失效媒体链接。
- [x] 步骤或素材变动后，原始摘要保持不变，界面区分历史记录与当前位置。
- [x] 通过现有前置工作台 HTTP API 与可见候选界面验证导航及缺失场景。
