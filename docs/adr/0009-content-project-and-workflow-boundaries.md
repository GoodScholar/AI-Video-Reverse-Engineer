# 以内容项目承载独立工作流与业务生命周期

内容项目是顶层本地工作单元，商品视频制作与参考复刻是其中可独立演进的工作流；项目素材通过稳定标识被制作计划、编辑序列、渲染运行和审核版本引用，各对象分别拥有版本与失效规则，不使用一个项目状态代表全部阶段。外部服务与运行队列只负责协议适配、执行快照和恢复，不拥有商品事实、镜头采用、审核或交付决定；最终 AI 视频生成继续遵循 ADR 0007 在外部工具完成。

默认产品入口是内容工作室。`?workspace=legacy` 作为旧版参考复刻工作台保留历史访问和原有数据修改能力，但不再承接新产品功能或重新开放最终生成提交。采用统一内容项目避免复制项目素材、凭据和交付历史；代价是各工作流必须通过明确对象和版本关联，不能依赖含义模糊的全局完成状态。
