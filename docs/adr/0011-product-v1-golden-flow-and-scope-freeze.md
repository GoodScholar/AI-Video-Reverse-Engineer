# 以商品短视频试点作为 v1 黄金流程并冻结新增模块

**状态：** accepted

**日期：** 2026-09-29

当前产品同时具备商品内容制作、批量混剪和参考复刻等能力，但若让每条工作流和所有未来模块共同决定发布，产品将长期无法形成可验证的完成点。我们决定以内部交付团队的商品短视频生产作为 v1 唯一黄金流程：核实商品事实与素材，真实生成并确认五条脚本候选，选声配音，制作至少两条差异化作品，完成字幕、预览、人工审核和批准版本导出。v1 完成要求 P0 技术基线和一个真实商品的试点交付同时通过；参考复刻及其他现有能力继续保留，但不阻塞 v1。

AI 商品内容创作、已有素材批量混剪和参考素材复刻是同一内容项目的三个开始入口，不是三种项目类型。它们共享项目素材、制作镜头、编辑序列、运行、审核和交付边界。P0 试点通过前不实施 P1、P2、延后或预留模块，只允许黄金流程验收、数据完整性、恢复、审核门禁、安全、许可证和既有范围冲突修复。

这是一项产品范围冻结，不是永久功能封禁。应用内发起外部生成、受限 Agent、时间线增强、自动发布或扩容基础设施可以在以后重新立项，但不得建立第二套业务真相源、绕过人工审核、用随机重排冒充智能能力，或把运行成功和模型评分当作批准。
