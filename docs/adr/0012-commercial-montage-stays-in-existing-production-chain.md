# 商用自动混剪保留现有生产链并采用本地召回与豆包复排

**状态：** accepted

**日期：** 2026-09-29

当前半自动批量混剪可以支持试点制作，但在系统仍需人工决定大部分镜头入点、顺序和节奏时，不宣称自动批量混剪已经达到商用标准。现有 P0 数据与审核边界收口后，商用自动混剪作为同一内容项目和批量混剪模块的下一阶段：本地完成片段切分、索引、召回和可恢复缓存，使用用户显式选择并完成外发披露的 `Doubao-Seed-2.1-pro` 对少量候选关键帧和必要文字进行复排与解释；服务失败时保留本地候选和明确失败，不静默切换供应商。

片段候选和混剪提案始终引用 `ProjectAssets` 的稳定素材身份，采用后进入现有短视频变体编辑序列；转场、花字、字幕模板、主体感知竖屏裁满、节奏建议和自动质检与智能选片同属第一期商用范围。成片继续由现有 Timeline、FFmpeg、预览、审核和交付链产生，不引入第二套项目、时间线、渲染或批准真相源，也不把模型评分或自动质检等同于人工审核。实现优先复用许可兼容的 PySceneDetect、Media Search Agent、OpenShorts、MoneyPrinterTurbo、FFmpeg、libass 和 librosa 局部能力，排除会引入非商业限制、AGPL 传播义务或平行运行时的整仓迁入。
