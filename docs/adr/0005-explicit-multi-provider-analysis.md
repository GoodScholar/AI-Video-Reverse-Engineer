# 使用用户显式选择的多供应商分析服务

Status: accepted

Date: 2026-09-12

Supersedes: ADR 0004

MVP 的分析服务边界支持阿里云百炼、OpenAI、Google Gemini、火山方舟豆包和 Anthropic Claude。用户在分析前明确选择供应商和产品已验证的模型；系统只把分析代理发送给该接收方，失败时不得自动切换。各供应商通过统一 `AnalysisProvider` 契约转换为稳定领域结构，API Key 使用系统安全存储，项目仅记录供应商、模型和分析版本。相比百炼单供应商方案，这提高了地域与模型选择灵活性并避免后续重构核心边界；代价是增加适配器、凭据配置和契约测试组合，因此第二批供应商与企业托管平台必须拆分为后续 Ticket。
