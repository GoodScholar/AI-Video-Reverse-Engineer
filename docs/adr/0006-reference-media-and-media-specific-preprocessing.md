# 采用统一参考素材与媒体专属预处理边界

Status: accepted

Date: 2026-09-12

复刻项目使用带有 `type` 的单一 `referenceMedia` 字段，而不并列维护图片和视频项目字段：这样每个项目始终只绑定一种参考输入，上传、替换、持久化和用户界面共享同一生命周期，媒体差异只在明确的边界处分支。读取旧 `projects.json` 时，在模型校验前将 `referenceVideo` 迁移为 `type: video` 的 `referenceMedia`；后续正常写入只保存新字段，已有视频素材与有效下游记录无需用户手工迁移。

参考图片不会被伪装成静态视频。这样既不会虚构动作、运镜、节奏或音频等时间事实，也不会让图片进入需要连续帧输入的视频预处理、深度捕捉或视频工作流。校验、存储、替换和展示使用统一参考素材边界；视频继续使用 FFmpeg、视频本地预处理与深度动作捕捉，图片只在其已实现的静态图片链路中处理。当前图片上传不启动视频本地预处理、深度捕捉、外部语义分析或 ComfyUI Workflow。
