# 统一混剪、创作画布与生成协调边界

**状态：** accepted

**日期：** 2026-09-30

产品采用三个稳定但不强制独立部署的能力边界：`RemixEngine` 统一承载已有素材重组与长视频拆短，`CanvasEngine` 拥有创作画布文档和依赖执行语义，`GenerationService` 统一协调文本、图片与视频生成。三者共享现有内容项目、项目素材、运行记录、版本、时间线、审核和交付真相源；模型推理、许可证要求隔离的组件或资源密集型运行时可以通过适配器作为外部服务存在，但不得由此建立平行的项目、任务、素材或批准系统。

`RemixEngine` 提供脚本驱动和高光驱动两个入口：前者从已确认脚本与多份项目素材形成计划，后者从单条长视频的转录与高光候选形成计划；两者最终进入同一计划、编辑序列、预览、审核和交付链。Anil-matcha/AI-Youtube-Shorts-Generator 固定提交 `a57bb938ba50bf9654c2d5ca2af1295163454349` 只把可审计的本地转录、分块、高光、去重、Top N 与竖屏重构能力纳入强制对齐范围；已知时码问题必须修正，主体跟踪按本项目商用目标补齐。MuAPI 仅可作为未来的可选适配器，不是验收前提，也不宣称其不可见服务端源码已被复用。

`CanvasEngine` 拥有画布文档、节点和端口、依赖校验、执行顺序、撤销重做、版本与分支续创，不直接拥有模型供应商、凭据、生成文件或混剪算法；生成节点委托 `GenerationService`，混剪节点委托 `RemixEngine`，结果通过稳定项目素材身份返回画布。`GenerationService` 的首个强制范围为文本、图片和视频；现有 TTS、音乐与字幕继续属于既有生产能力，在另有明确需求前不为统一接口而重构。ComfyUI 是可选生成适配器，不是服务定义或强制依赖。

`RemixPlan` 是两个混剪入口共享的唯一版本化计划协议，“混剪提案”是用户可查看、保存和采用的一份候选 `RemixPlan`；采用时按来源关系物化为现有编辑序列，计划本身不成为第二套时间线。`RemixEngine` 协调输入分析、候选、计划、采用以及通过现有 Timeline/FFmpeg 形成预览，但不拥有独立渲染器、审核或交付系统。计划允许声明缺失的旁白、图片或视频；只有用户确认 Provider、外发内容和可能费用后，才委托 `GenerationService` 生成、形成项目素材并重新解析计划，不得把自动生成设为已有素材混剪的强制步骤。

三个边界共用一个持久运行基础设施和公共运行标识，同时保留 `RemixRun`、`CanvasExecution` 与 `GenerationRun` 的领域状态、输入快照和结果语义；公共层负责排队、取消、恢复、幂等和日志，不使用三套队列，也不把全部状态压成无语义通用 JSON。成功的图片、视频和音频输出立即形成不可变、可追溯的项目素材版本；文本结果保留为不可变生成运行输出，只有采用后才成为画布文本、脚本版本或其他领域内容。

每次生成运行绑定明确的 Provider、模型、能力快照、输入快照和披露记录。仅当用户保存了显式路由策略时才允许自动选择或回退，并必须记录实际选择；没有该策略时，Provider 或模型失败即明确失败，不得静默切换。

“约定范围 100% 对齐”以五张关联矩阵为分母：三引擎架构与共享真相源、`RemixEngine`（含既有商用混剪规格和 Anil 本地长视频拆短链）、`CanvasEngine`（含既有完整画布规格）、`GenerationService`（文本、图片、视频）以及跨引擎真实闭环。验收项只允许“通过、失败、阻塞、明确不适用”；失败和阻塞均为未闭合差异，“不适用”只能在冻结分母时明确决定并记录理由，不能在实现受阻后用于缩小范围。

证据按能力风险组合固定源码与许可证映射、自动化行为测试、真实媒体或真实 Provider 运行记录，以及需要视觉或内容判断时的人工验收。模拟 Provider 只能证明协议和异常行为，不能替代真实生成、真实成片或构图质量。每种生成模态至少有一个真实 Provider 完成提交、状态读取或流式响应、取消语义、失败恢复、结果入库和下游使用；所有对外显示为支持的 Provider 均须分别通过真实冒烟，未配置或未验证的适配器不得显示为已支持。

每项源码复用须记录上游仓库、固定提交、源文件、许可证、复制或移植范围、本项目落点、必要改动和测试证据；自行实现与仅参考设计的部分分别标明。只有所有已宣称复用条目可追溯，才可称“源码复用记录 100% 完整”，不得用参考仓库数量、复制代码行数或已经读过源码代替实际复用。

允许分别声明某张矩阵或某个冻结切片达到 100%，但不得据此宣称整个产品完成。只有五张矩阵全部通过、跨引擎差异清零时，才可声明“本次约定范围整体 100% 对齐”。

Anil 本地长视频拆短切片以 `faster-whisper` 为强制本地转录实现，保存词级和段级全片绝对时间。默认在视频超过 30 分钟时使用 20 分钟块和 60 秒重叠，策略及版本随运行保存；提示模型时可以采用块内相对时间，但进入领域数据前必须转换并校验为全片绝对时间，不能保留上游重复叠加 offset 的缺陷。`whisper.cpp` 仍可用于其他场景，但不能冒充该切片已复用 `faster-whisper`。

高光候选保存稳定身份、全片起止时间、评分维度、总分、选择理由、转录证据、模型与提示版本及来源分块。无效模型输出必须明确重试或失败；去重使用版本化策略，默认兼容上游“候选与已保留项的重叠超过候选自身时长 50% 时抑制低分项”，同时增加对称重叠测试和确定性排序。

正式竖屏主体重构不能把上游“最大 Haar 人脸 + EMA”当作商用终点。能力范围包括人物、人脸和商品等主体、跨帧身份保持、场景切换后重新选择、版本化裁剪轨迹、主体框、置信度及人工关键帧覆盖；最终 9:16 不得用黑边冒充裁满，无法安全构图时必须标为待处理。Haar 路径只能作为明确记录的最低回退。

请求生成 N 条短视频时，运行保存请求数、候选数、成功数、失败数以及每条结果的唯一身份和来源。单条失败不得删除成功结果，可从检查点重试；取消、进程重启、输出重名、无语音、无有效高光和模型无效响应均有确定状态。只有 N 条均成功才标记完整成功，否则标记部分成功或失败。

“100% 对齐”表示全部冻结门槛通过，不表示概率模型永远判断正确。既有商用混剪金标继续要求镜头保留率至少 80%、人工替换率不超过 20%；长视频高光另行记录金标召回与采用率。黑边、越界时码、错误素材身份、未披露外发和未经批准交付是零容忍工程错误。长视频拆短真实金标至少包含六份已授权并人工标注的视频：30 分钟以内单人、超过 30 分钟多分块、多人交替、商品或非脸主体、快速运动与场景切换、无语音或无有效高光；每份都须完成真实转录、Top N、竖屏成片、项目素材入库、预览和人工检查。合成媒体只用于确定性自动测试，不能替代该真实验收。

长视频输入强制支持本地路径、YouTube、B站、抖音、小红书和快手。所有来源都经过来源识别、元数据探测、用户权利确认、下载或导入、内容哈希与来源记录，形成项目素材后才能进入 `RemixEngine`；下游不得继续依赖外部 URL。强制范围支持公开页面、正常分享链接以及用户显式提供合法账号会话后可访问的内容；Cookie 或令牌只进入系统安全存储，不进入项目文件或日志。产品不自动输入密码或扫码登录，也不绕过 DRM、会员权限或私密访问控制。

YouTube、B站、抖音和小红书可以优先使用固定版本的 yt-dlp 适配器；快手使用独立 `KuaishouSourceAdapter` 或另一个经过固定版本、许可证和真实下载验证的实现，不能因通用 URL 偶然成功一次就宣称支持。每个平台保存适配器版本、最近真实验证时间和 `可用 / 需要登录 / 暂时失效 / 不支持该链接` 状态；平台范围的 100% 验收绑定固定依赖版本和金标 URL 集，第三方站点变化导致的运行失败必须明确显示并保留诊断证据。

统一 `GenerationService` 采用门面与适配器注册表，不删除或无故重写已经验证的文本、图片服务；现有实现满足统一契约后作为适配器保留，视频能力通过新增适配器接入，画布对具体服务的直接编排逐步收口到统一门面。生成请求使用公共信封加模态专属结构：公共部分保存模态、Provider、模型、配置版本、输入快照、披露、幂等键和调用来源，文本、图片和视频各自保留经能力目录验证的参数，不退化成只有 `prompt` 的最低公共协议，也不把 Provider 任意 JSON 直接暴露给画布。

文本强制支持普通流式结果、文本与图片稳定引用、可选结构化 Schema、输出预算、取消、超时、结果不完整及计费未知，并能被明确采用为画布文本、脚本版本或 `RemixPlan` 输入。图片强制支持文生图、单图或多图参考、模型允许时的图片编辑、多结果、比例和分辨率校验、逐结果失败、取消及项目素材入库；普通本地裁切和缩放不冒充模型编辑或超分辨率。视频强制支持所选模型真实声明的文生视频、图生视频、首帧或尾帧、多参考输入、时长、比例、分辨率和音频能力组合；异步运行持久保存远端任务 ID，能够重启后查询、表达真实取消语义、安装结果为项目素材并供下游续创。每种模态至少有一个真实 Provider 完成这些适用能力的端到端验收。

`ComfyUIAdapter` 是正式扩展点，但不属于首个整体 100% 的强制前提。若界面宣称已经支持 ComfyUI，则其 Workflow ID、输入映射、队列、WebSocket 或轮询、取消与结果入库须独立通过真实验收。每个适配器提供版本化且经官方资料或真实探针确认的能力描述；服务端按该目录校验输入数量、模态、比例、分辨率、时长和取消能力。未知能力不展示也不接受，保存配置或连接成功不等于能力已经验证。

`CanvasEngine` 的验收分母承接 `.scratch/ai-creative-canvas/spec.md` 全部 35 条用户故事，不因实现困难重新缩小。Toonflow 固定提交继续作为主视觉与主体交互基准，其他固定参考只补充其缺少的能力。可执行数据依赖是经过端口和类型校验的有向无环图；注释、分组及纯视觉关系可以使用不参与执行的关系边。检测到执行环时阻止执行并保留关系证据，不静默删边。

`CreativeNode` 保存稳定身份、类型、端口、配置、引用和执行状态，`CanvasNodeView` 只保存位置、尺寸、折叠和其他视图状态；节点类型通过受控注册表扩展，不能把 React Flow JSON 当作唯一业务数据。每次画布执行冻结画布修订、依赖子图、输入顺序、配置和能力快照，历史运行不可变；节点只保存当前选中输出的稳定引用。切换输出或改变上游会使下游明确过期，只有用户再次执行时才产生新运行，不自动重复计费。

首期包含受控 `AgentAction`：Agent 使用与人工操作相同的领域命令，先生成可查看的变更提案，经用户确认后应用；操作可审计、可撤销，不得直接改数据库、越权调用 Provider 或自动批准交付。自主长期循环不在首期范围。多人实时协作也不属于首个整体 100% 的分母；当前仍须完成单用户多窗口版本冲突、草稿恢复和并发保存保护，Yjs 只作为后续能力保留。

创作画布页面以 Toonflow 固定提交 `d86cce6b689916ab73f75bc4c1f42a2a7424516c` 为唯一主体页面结构、节点外观、浮动工具和编辑器基准。实现前必须读取对应页面、组件、状态及交互源码；许可证和技术栈允许时直接复制组件或主体结构，只适配本项目 API、状态、项目素材身份和 React/XYFlow 接缝。无法直接复制时记录具体原因，再保持同形结构和交互完成必要适配，不允许只看截图重写简化版本。

画布适用独立设计例外：采用 Toonflow 的全幅画布、顶部区域、添加入口、节点、就近浮动工具、画布控制及按需属性编辑结构，不为旧站点侧栏、表单卡片、设计变量或组件外观删减主体交互；只把导航返回、项目身份和共享状态接入现有应用。basketikun/infinite-canvas 补充媒体节点、生成记录、引用、插件、剪贴板和续创，XYFlow 提供底层画布交互；其他项目只补充经过独立源码与许可证核查的缺失能力，不能改写主体页面骨架。

画布 UI 验收固定参考应用版本、视口、节点数据和操作状态，逐项比较页面区域、节点层级、工具位置、打开或关闭行为、拖拽连线、选择、多选、菜单和编辑器。允许差异必须来自项目数据、API 或平台限制并写入差异记录，未批准的结构和主体交互差异必须为零；截图差异是辅助证据，真实操作步骤或录像是必需证据。每个复制或改造组件记录上游文件、固定提交、许可证、本项目落点和适配点，并区分直接代码复用与设计参考。

五张矩阵共同通过还要求三条真实跨引擎金标闭环：一是本地或平台视频入库后完成转录、高光、竖屏重构、`RemixPlan`、N 条变体、预览、审核与批准导出；二是已确认脚本和多项目素材形成提案，缺失素材经用户确认后由生成服务产生并入库，重新解析计划后形成多变体交付；三是画布文本节点依次驱动真实图片与真实视频生成，结果成为项目素材并用于下游续创或混剪，最终进入预览和审核。API 分别成功不能代替这些闭环。

本地、YouTube、B站、抖音、小红书和快手各至少使用一份授权样本完成真实导入、哈希、来源登记及素材预览；其中至少一份超过 30 分钟的样本继续完成完整高光拆短链，不要求六份样本重复相同的昂贵后处理。上游失败、取消、状态未知或输入修订变化时，下游必须显示阻塞或过期；本地停止不冒充远端取消，迟到结果保留但不自动采用。重试使用新运行身份和幂等规则，重启或刷新不得重复产生计费请求。

来源素材、脚本、文本/图片/视频生成结果、当前选中输出、`RemixPlan`、编辑序列、裁剪轨迹、包装模板、字幕、音频、模型或配置版本发生影响成片的变化时，所有依赖预览和批准明确失效，历史记录继续保留。旧画布文档、混剪提案、编辑序列、项目素材和运行记录必须可读取或经幂等迁移升级；迁移前保留备份，失败不覆盖原数据，现有文本和图片生成结果不得因统一接口而重新生成或丢失来源。

缺少真实 Provider 凭据、合法平台样本、人工视觉验收或上游授权链时，对应验收项保持“阻塞”且不从分母删除。ViralVadoo 来源尚未确认不阻止独立实现相同行为，但阻止复制来源不清的代码；只有全部阻塞和差异清零，才能声明本次约定范围整体 100% 对齐。

粘贴选型文本是产品方向与能力目标，固定参考源码是实现事实来源：源码缺失、缺陷或宣传边界由本项目适配、修正或替换，不把逐行复制当作对齐。正式的“100% 对齐”只针对书面冻结的能力矩阵，要求范围内实现、数据关系、正常和异常行为及真实运行证据全部通过且差异清零；源码复用比例单独记录。

本决定取代 ADR 0007 和 ADR 0010 中“最终 AI 视频生成只在外部工具完成”以及“以受控镜头关系图限定整个创作画布”的相关结论。外部模型运行时、能力声明与数据发送约束继续遵循 ADR 0005；商用混剪继续复用既有生产链并遵循 ADR 0012。旧数据和历史 ADR 保留用于追溯，迁移不得丢失既有项目、素材、运行或结果。
