# 需求分流标签

| 标准角色 | 本项目状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 Agent |
| `ready-for-human` | `ready-for-human` | 必须由人工处理 |
| `wontfix` | `wontfix` | 决定不实施 |

工程技能提到某个标准角色时，应使用对应的项目状态。
